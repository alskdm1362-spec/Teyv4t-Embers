# v0.29 — 닫기 버튼 겹침, 주 버튼 톤, 상점·레이드·세이브 데이터 화면

기준: v0.28(main, PR #4 병합) 위, 브랜치 `claude/v0.29`.

## 수정
- 제목 없는 창(도감·환경설정·상점·지원 편성·레이드·세이브 데이터 등)의 닫기 버튼에 오른쪽 위 전용 줄을 따로 두었다. 이제 탭이나 첫 줄과 겹치지 않는다.
- 주 버튼(`button.primary`): 밝은 금색 판을 걷어 내고, 어두운 바탕에 황동색 테두리·글자·밑줄을 쓴다. 도감 활성 탭과 카드 열람 '닫기'도 같은 톤으로 맞췄다.
- 튜토리얼: 사라진 것이 아니다. 첫 원정을 마치면(`collection.tutorialDone`) 다음 원정부터 건너뛴다. 환경설정 › 저장 · 안내에 "튜토리얼 다시 하기 · 다음 새 원정"을 추가했다.

## 화면(카제나 스크린샷 참고)
- 상점: 키라라를 배경에 세우고, 아래 캡슐 진열대에서 장비를 고른다. 오른쪽에는 장비 설명과 파티 전원의 장착 칸, 그리고 "구매·장착 / 교체 / 보유품 장착 / 장착 중" 버튼이 나온다. 보유한 엘리트 장비도 진열대에 함께 보인다.
- 보스 레이드: 보스 그림을 크게 두고, 누적 피해 패널을 붙였다. 오른쪽 패널에는 규칙, 세 칸 편성 슬롯, 세이브 데이터 목록, 도전 버튼이 들어간다.
- 세이브 데이터: 전투원 탭(초상), 왼쪽 슬롯 열(빈 칸 포함), 오른쪽 상세(가치, 장비 두 칸, 레벨·카드 수·각성·승리 전투, 덱 그리드, 로비에서만 삭제).
