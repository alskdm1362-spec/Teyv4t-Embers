# 0.14 · 정신 붕괴 일러스트 교체와 시각 단계

2026-11-23. 사용자 제공 `정신붕괴 일러스트 교체.zip`의 네 캐릭터 × 두 단계 PNG 8장을 그대로 적용했다. 원본을 변환하거나 다시 그리지 않고 CSS로 컷인·초상화·카드의 표시 위치를 조정한다. 파일명·크기·SHA-256은 `dist/assets/collapse-stages/manifest.json`에 기록한다.

| 극복 실패 횟수 | 표시 그림 | 컷인 |
| --- | --- | --- |
| 붕괴 진입, 실패 0~3회 | 1단계 | 붕괴 진입 시 한 번 |
| 4회째 실패 | 2단계로 전환 | 새 2단계 컷인 한 번 |
| 실패 5~10회 | 2단계 유지 | 추가 재생 없음 |
| 붕괴 극복 / 정신 안정 | 기본 그림 | 단계 상승 컷인 없음 |
| 기존 저장 불러오기 | 저장된 실패 횟수로 결정 | 자동 재생 없음 |

시각 단계는 기존 `breakdown.failures`에서 계산한다. 별도 단계 값을 저장하지 않으므로 구버전 저장/거점 체크포인트가 그대로 맞는 그림을 표시한다. 성공 확률·실패 효과·10회 실패 후 다음 시도 확정 회복·RNG·성장·부상은 바꾸지 않았다. 기존 1~3의 효과 강도는 그림 단계와 혼동하지 않도록 `위험 강도`로 표기한다. 실패 7회 이후에도 그림은 2단계다.

교체 범위는 붕괴 컷인, 상태 창, 전투 HUD 초상화, 붕괴 카드/소유자 표시, 정신 안정 선택/대화, 도감 감상이다. 도감은 기본/붕괴 1단계/붕괴 2단계를 고를 수 있고, 단계별 컷인 항목의 연출 버튼이 선택한 단계를 재생한다. 도감 감상은 실제 파티 상태를 바꾸지 않는다. 대화의 기본 포즈 복귀 지시도 유지한다.

이전 붕괴 컷인·스탠딩·초상·카드 그림 24개와 사용하지 않는 초기 프로토타입 3개를 배포 파일에서 제거했다. 폐기 경로는 `references/supplied/retired-collapse14.json`, 이전 해시 기록은 각 자산 manifest의 `retired_assets`에 남겼다. 전투 도트 리소스는 전용 역할로 유지한다.

유리 연출은 일러스트보다 뒤(z=0, 그림 z=1)에 남기고 불투명도를 1단계 0.44 / 2단계 0.68로 높였다. 2단계는 더 빠른 균열 형성과 약한 발광·대비, 2.6초의 재생을 사용한다. 짧은 연출/기기 동작 줄이기는 기존 설정을 따른다. 설명 글자는 선명한 유리 선과 겹쳐도 읽히도록 검은 외곽 그림자를 쓴다.

## 검증

- 자동 검사 108개 통과. 네 캐릭터·네 붕괴 유형의 실패 횟수 0~10, 실제 카드 사용의 3→4회 실패, 다른 실패/회복/저장 복원의 중복 컷인 방지, 신규 PNG 해시, 폐기 경로 제거, 기존 전투 리소스 유지, 정신 안정 기본 포즈 지시, 도감 두 단계와 QA의 입력 범위를 검증했다.
- 실제 브라우저에서 로엔 붕괴 카드를 사용해 4회째 실패의 2단계 컷인과 남은 카드/초상화 전환 확인. 5회째 실패에서는 컷인 없이 같은 그림 유지. 새로 고침 후 테스트 저장을 이어도 2단계가 유지되고 컷인은 재생되지 않음.
- 네 캐릭터의 두 단계 미리보기, 844×390 가로 컷인, 390×740 세로 감상/컷인, 상태 창 그림/탭, 도감의 두린 2단계 연출 확인.
- 로엔의 정신 안정 대화를 1/9부터 끝까지 진행해 새 2단계 그림→기본 초상화·정신 부담 0·지속 글리치 제거 확인.
- 핵심 화면은 `docs/screenshots/embers-14-*.jpg`. 실기기 터치·장시간 성능 및 전체 캠페인 재플레이는 이 변경의 검수 범위에 포함하지 않는다.

QA에는 `붕괴 1→2단계 전환 직전`, 극복 실패 횟수, 붕괴 미리보기 단계 선택을 추가했다. 이 상태/피드백 저장은 본편과 분리된다.
