# v0.27 — 세이브 데이터, 로비 분리, 보스 레이드, 번뜩임

카오스 제로 나이트메어처럼 "원정(런)에서 빌드를 만들고, 원정이 끝나면 전투원별 세이브 데이터로 남겨 레이드에 쓴다"는 구조로 바꿨다. 사용자 선택: 전투원별 세이브, 클리어·실패 모두 기록, 전투 중 번뜩임, 로비·전투·지도/보상·전투원 상세 화면 손보기.

## 구조: 로비 ↔ 원정
- 로비는 원정과 별개의 허브다. 원정은 `runActive` 플래그로 진행 여부를 표시한다.
- 로비에서 **새 원정 시작**(`newExpedition`): 수집 기록(해금·도감·컷인·엔딩·세이브 데이터·레이드)만 이어받은 새 원정을 만든다. 튜토리얼은 처음 한 번만 하고, 이후 원정은 튜토리얼 없이 시작한다(`collection.tutorialDone`).
- **원정 이어하기**: 거점에서 "임시 저장 후 로비로"로 나왔다면 거점으로, 다른 화면에서 나왔다면 그 화면 그대로 돌아간다(`resumePhase`). 전투 중에 로비로 나가도 전투가 지워지지 않는다.
- **원정 종료**(`finishExpedition`): 엔딩(클리어), 전멸, 거점·로비(귀환)에서 할 수 있다. 튜토리얼 중에는 불가.
- 엔딩 화면: 원정 종료 · 세이브 데이터 기록 / 이전 거점으로 / 기록 보기. 전멸 화면: 거점에서 다시 시작 / 원정 종료 · 세이브 데이터 기록. "새 캠페인" 버튼은 로비의 새 원정으로 대체했다.

## 세이브 데이터 (dist/savedata.js)
- 원정을 끝내면 참여한 전투원마다 스냅숏을 만든다: 레벨, 획득·제거 카드, 디버프 카드, 전술 각성, 잔불 각성, 장비, 덱 목록, 결과(클리어·전멸·귀환).
- **가치**: 획득 카드 +10, 각성 +10, 잔불 각성 +20, 카드 제거 +10, 장비 +10(엘리트 +20), 디버프 카드 -5. 빌드를 얼마나 키웠는지 보여 주는 숫자이며 아직 상한이나 제한은 없다.
- 전투원당 3칸(`SAVE_SLOTS`). 칸이 가득 차면 교체할 기록을 골라야 한다. 각 전투원마다 기록하기 / 남기지 않기를 정한 뒤 로비로 간다.
- 세이브 데이터는 로비의 세이브 데이터 메뉴와 전투원 상세의 "세이브" 탭에서 볼 수 있고, 로비에서 삭제할 수 있다.

## 보스 레이드
- 열림(`RAID_AVAILABLE=true`). 세이브 데이터 1~3개로 출격하며 전투원당 하나만 고를 수 있다.
- 편성(세이브 데이터 조합)마다 3회, 6턴. 편성별 최고 피해의 합이 보스 누적 피해(240)가 된다.
- 레이드 중에는 진행 중인 원정을 통째로 보관했다가(`raidStash`) 정산 후 그대로 되돌린다. 레이드 덱은 세이브 데이터에서 다시 만든다.
- 예전 파티 단위 "원정 기록"으로는 출격할 수 없다(기록 자체는 저장에 남는다).

## 번뜩임 (전투 중 각성)
- 카드를 뽑을 때 3% 확률로 빛난다(전투당 1장, 튜토리얼·레이드 제외, 이미 각성한 카드·생성 카드·디버프 제외).
- 빛나는 카드는 비용 0. 사용하면 네 각성 방향 중 세 개를 완성된 카드 모습으로 나란히 보여 주고 하나를 고른다. 낮은 확률(두린이 있으면 25%, 아니면 10%)로 한 방향에 잔불 각성이 붙는다. 흘려보낼 수도 있다.
- 고른 각성은 이 원정 동안 유지되고 세이브 데이터에도 남는다.
- 거점·사건·전리품의 "전술 각성"도 같은 미리보기 화면(지금 카드 → 네 방향)으로 바꿨다.
- 번뜩임으로 덱이 강해지는 만큼 9번째 지점 이후의 적 강화를 체력 ×1.10→×1.50, 피해 ×1.10→×1.40으로 조금 올렸다. 자동 45판 기준 한 판 평균 붕괴 0.82회, 전멸 0.80회, 클리어 40/45.

## 화면
- **로비**: 왼쪽 위 로고, 오른쪽 위 세이브 데이터 수·레이드 누적·해금 전투원, 오른쪽 큰 메뉴 타일(원정 · 보스 레이드 · 세이브 데이터 · 전투원·파트너 · 도감), 왼쪽 아래 원정 상태 카드(진행 중: 이어하기/원정 종료, 대기 중: 새 원정 시작).
- **전투**: 각 전투원 발밑에 정신 부담 게이지(붕괴 시 붉게 깜빡임). 번뜩임 카드는 금빛으로 빛나고 "번뜩임" 표시가 붙는다.
- **세이브 데이터 기록 화면**, **레이드 편성 화면**(보스 정보와 전투원별 세이브 카드), **세이브 데이터 창**, **전투원 상세 "세이브" 탭**을 새로 만들었다.
- 지도·보상 화면은 v0.26의 분기 지도와 카드 보상을 유지했다.

- 로비 → 레이드 편성(2명) → 레이드 전투 → 트라이 정산 → 로비(원정 상태 복원).
