## 바뀐 규칙 (나모 님 결정)
- 결합 전에 사이노 카드를 써야 한다는 조건을 **뺐다**. 손에 죄·명계와 **사용 불가 카드만** 남으면 저절로 결합한다(누가 마지막 카드를 썼든).
- 이름: 명멸검 → **심판**(사이노10) · 편린:명 → **심판 · 죄**(사이노9) · 편린:암 → **심판 · 명계**(사이노12) · 검수 → **심판 · 의식**(사이노11), 결속 → **판정**.
- 명·암 발동: **죄 = 사이노 카드**, **명계 = 동료 카드 2장**.

| 카드 | 비용 | 키워드 | 효과 | 출처(로스바이세) |
|---|---|---|---|---|
| 심판 | 0 | 유일 · 명암 | 피해 400%. 결합한 턴에는 판정 1당 +80% | 명멸검 0코 400% |
| 심판 · 죄 | 2 | 유일 · 보존 | 무작위 적 피해 80%, 판정 +1. 사이노 카드를 쓸 때마다 저절로 발동(턴당 2회). 손패 맨 왼쪽 | 편린:명 |
| 심판 · 명계 | 2 | 유일 · 보존 | 무작위 적 피해 80%, 판정 +1. 동료 카드 2장마다 저절로 발동(턴당 2회). 손패 맨 오른쪽 | 편린:암 |
| 심판 · 의식 | - | 사용 불가 · 보존 | 판정 1~20. 결합할 때 판정 1당 이번 턴 심판 기본 피해 +80% | 검수 (결속 1·20) |

**흐름**: 턴 시작(전투 시작 포함) 때 죄·명계가 손에 없으면 심판을 손으로 가져와 죄·명계·의식(판정 1)으로 나눈다(턴당 1회) → 다른 카드를 쓰는 동안 죄·명계가 저절로 발동하며 판정이 쌓인다 → 손에 죄·명계와 사용 불가 카드만 남으면 심판으로 결합 → 0코스트 심판으로 한 방 → 다음 턴 시작에 다시 나뉜다. 죄나 명계를 직접 써서 손에서 빠져도, 다음 턴 시작에 흩어진 조각을 모아 다시 나눈다.

**심판의 분기 = 명멸검 변형** (분기가 죄·명계의 피해와 발동 조건도 바꾼다)
| 분기 | 심판 | 죄 / 명계 발동 조건 | 죄·명계 피해 | 출처 |
|---|---|---|---|---|
| 기본 | 400% | 사이노 카드 / 동료 카드 2장 (턴당 2) | 80% | 기본 |
| A 안정 | 600% | 같음 | 120% | 강화 |
| B 자원 | 600% | 능력으로 버릴 때 / 능력으로 뽑을 때 (턴당 2) | 120% | 순환 |
| C 변형 | 400% + 본인 보호막 120% | 사이노 피격 / 사이노 보호막 획득 (턴당 1) | 240% | 수호 |
| D 빌드 | X: 400% + 행동력 1당 120% (종극) | 능력으로 행동력 획득 / 비용 1 이상 카드 (턴당 2) | 120% | 무한 |

**함께 바뀐 카드**
- 기존 편린 셋은 일반 카드로: 창 찌르기(100%, 시작 덱 ×2) · 검은 발톱(70%, 조준점 +50%) · 심판관의 응시(판정 +3, 로스바이세의 「검의 공명: 검수 3장 생성」).
- 명계의 깃털 삭제(그림 사이노9는 「죄」가 씀). 시작 덱: 심판 · 창 찌르기 ×2 · 침묵의 자세.
- 대풍기관의 권한: 0코 · 유일 · 개전, 2장 드로우 + 이번 전투 의식이 판정 2로 시작(키르켄의 사도: 드로우 2).
- 침묵의 자세 C → 판정 +1. 일곱 성인의 소환 C → 판정 +2, D → 3장 뽑고 3장 버림. 낮은 자세는 「심판」 카드를 버리지 않는다.
- 필살기: 단일 피해 350%, 다음 심판에 그 피해의 30% 고정 피해(백야명멸: 다음 명암 카드 발동 시 고정 피해 30%).
- 타이나리: 죄·명계의 무작위 피해가 조준점이 붙은 적을 먼저 노린다.
- 새 키워드 **명암**(키워드 12종, 가이드 자동 반영).
