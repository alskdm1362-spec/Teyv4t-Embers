# v0.25 — 제공된 화면 구조 유지 및 열람·대화 보정

## 변경
- 제공된 상세 정보 구성(왼쪽 캐릭터, 능력치/카드/파트너 탭, 중앙 스탠딩, 오른쪽 정보)을 유지하고 창·버튼 톤과 비율만 조정.
- 같은 열람창의 캐릭터/탭 변경 시 바깥 창을 유지하고 내용만 짧게 전환.
- 원정 보유 카드/뽑을 카드/버린 카드에서 동일한 카드 상세·전술 각성 비교 화면 사용. 원정 상세의 좌우 탐색은 실제 보유 카드 기준.
- 각성 방향별 카드와 각성 선택 중 미리보기 카드를 눌러 효과 확대 가능. 닫으면 이전 선택 방향으로 복귀.
- 전투 기록 상단 이동, 아래쪽 투명 그라데이션.
- 로비 대사 제거. 영입 연출 전체 배경 덮개 제거.
- 튜토리얼 대화는 합류 대화와 동일한 viewport 배율과 인물/대화상자 크기 사용. 정신 안정 인물 영역의 중첩 높이 축소 제거.
- 두린/야호다/일루가의 요청한 칭호 적용. 파트너 지원 스킬을 스탠딩 하단 이내로 제한.

## 일러스트3(1).zip
- 로비 배경 1장: 배경에 이미 두 인물이 있어 별도의 중앙 로엔 스탠딩은 이 로비에서 숨김.
- 필살기 컷인 4장: 캐릭터별 컷인, 열람, 도감의 공통 역할 경로 적용.
- 붕괴 컷인: 일루가 1/2단계, 로엔/두린 2단계만 교체. 기존 붕괴 스탠딩·HUD 초상·카드 일러스트 유지.
- 배경 A 6장과 B 3장: 후반 원정의 심연 구간에서 천공 구간 순으로 적용. 보상·경로 선택도 같은 구간 배경 유지.
- WebP 변환, 원본 파일명/역할/배포 파일 해시는 assets/update25/manifest.json에 기록.
