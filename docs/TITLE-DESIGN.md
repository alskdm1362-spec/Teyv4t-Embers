# 0.10 타이틀 방향과 레퍼런스

## 시각 자료 확인

- ELDEN RING 타이틀 캡처: https://endgameviable.com/gaming/2022/03/elden-ring-the-journey-part-1/ — 큰 로고, 짧고 좁은 메뉴, 한 항목에 집중하는 선택 표현과 어두운 여백을 관찰했다.
- Reverse:1999 타이틀 캡처: https://note.com/sallyb_ws/n/ne5f0001ba240 — 장면 자체가 분위기를 전달하며 로고와 시작 표시가 분리되는 구성을 관찰했다.
- 이미지 검색의 명일방주 타이틀에서도 단일 시작 행동에 집중한 구성을 보조 참고했다.

참고 자료는 작업 중 시각 비교용이다. 런타임 이미지는 기존에 제공된 title-main.webp/title-logo.webp를 그대로 사용한다. 폰트는 이미 포함된 LevelUp와 Paperlogy만 사용한다.

## 적용

- 실제 로고 영역의 투명 여백을 CSS 컨테이너로 정리해 로고의 보이는 크기를 정확하게 배치한다. 원본 파일은 변경하지 않는다.
- 차가운 청색 배경, 아이보리 타이포, 절제된 금빛 선택 표시. 제공 로고의 보랏빛은 저채도 배경 위에서 제목의 식별 요소로 유지한다.
- 큰 사각 버튼과 넓은 네온 번짐 대신 얇은 선·작은 마름모 선택 표시, 규칙적인 중앙 정렬과 여백을 사용한다. 본 행동은 LevelUp400/선택700, 보조 문구는 Paperlogy.
- 타이틀 배경은36초 주기의 작은 확대/이동, 안개2층은29/39초 이동, 잔불18개는13~26초 주기. 강한 섬광은 사용하지 않는다. 움직임 줄이기 환경에서는 이 애니메이션들을 모두 정지한다.
- Touch To Start→메뉴는 장면 DOM을 유지한 상태에서 로고 위치·크기와 메뉴만 전환한다. 배경 이미지와 음악 재생 요소를 새로 만들지 않는다.
- 유효한 진행 저장이 있으면 이어하기를 첫 행동으로 표시하고 파티/현재 지점을 안내한다. 제목만 저장된 초기 상태는 진행 저장으로 취급하지 않는다. 기존 시작/이어하기/통합 메뉴 동작으로 연결한다.
- 방향키 위·아래/Home/End로 메뉴의 활성 항목을 이동하고 Tab/Enter도 지원한다. 비활성 이어하기는 진입 애니메이션을 제외하여 흐린 상태가 유지된다.
- 타이틀은 기기 화면의 실제 CSS 크기로 배치한다. 이전의1280/1100 기준 게임 배율을 타이틀에까지 적용해 작은 휴대폰에서 글자가 축소되던 문제를 피한다. 전투·거점은 기존 자동 배율을 사용한다.

## 검증

79개 회귀 검사와 실제 브라우저 검증. 상세 결과는 QA.md의0.10 항목. 실제 휴대폰 기기의 터치 감각과 시각적 취향 평가는 별도 사용자 플레이가 필요하다.
