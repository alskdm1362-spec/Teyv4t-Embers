# v0.30 — 전투 스프라이트 교체, 몬스터 재구성, 레이드 보스 케루빔

기준: v0.29(main, PR #5 병합) 위, 브랜치 `claude/v0.30`.

## 전투원 스프라이트
- 받은 포즈 그림으로 교체했다: 대기 / 공격1·2 / 방어 / 강화 / 드로우 / 정신 붕괴(전투원마다 있는 포즈만).
  - 대기 → `assets/cast/<id>/battle.webp`, 정신 붕괴 → `assets/illustrations3/battle-collapse/<id>.webp`, 나머지 → `assets/cast/<id>/pose-<pose>.webp`.
- 포즈마다 정사각형 캔버스에 발이 아래 가운데 오도록 배치했다. `CAST_FOOT_X`는 모두 .5다.
- `CAST_SPRITES`(cast-art.js)에 두 값을 둔다.
  - `base`: 대기 그림이 예전 스프라이트와 같은 키로 보이게 하는 배율.
  - `poses[x]`: 대기 캔버스 대비 각 포즈 캔버스의 크기. 화면에서는 CSS `scale`로 맞춘다.
- `BattleMotion.pose()`는 카드를 낼 때 포즈를 고른다.
  - 피해를 주면 공격(1·2 번갈아).
  - 드로우가 있으면 드로우.
  - 보호막·대신 맞기·방어 카드면 방어.
  - 그 밖에는 강화(없으면 방어).
  - 약 0.4초 뒤 대기로 돌아간다. 붕괴 중이면 포즈를 바꾸지 않는다.
- 수동 확인 도구 `tests/vfx-review.html`의 적 미리보기 그림도 새 몬스터 그림(abyss-tick)으로 바꿨다.

## 몬스터
- 기존 도트 몬스터 그림(assets/generated의 적 PNG 10개)을 삭제했다. 받은 그림 19장을 `assets/enemies/*.webp`로 옮겼다.
- 전투 규칙은 그대로 `ENEMIES` 종류(hound, angler …)에 두었다. 겉모습은 `enemy-looks.js`의 "외형(look)"이 정한다: 이름, 그림, 영역(심연/천공), 크기.
- 지도의 첫 1/3은 심연이다. 그다음 1/3은 전투 셋 중 하나가, 마지막 1/3은 셋 중 둘이 천공 영역으로 바뀐다. 시드와 노드로 정해진다(`battleRealm`).
- 저장 중이던 전투는 불러올 때 외형과 새 이름이 붙는다.
- 도감 '적' 탭은 외형 19종을 이름과 함께 보여 준다. 적 정보에는 외형 설명이 추가됐다.

| trainingSlime | 떠도는 점액 | — |

## 보스 레이드
- 보스 이름을 '천공의 사도·케루빔'으로 바꿨다. 기존 저장도 불러올 때 바뀐다.
- 레이드 화면과 전투 모두 케루빔 그림을 쓴다. 불러내는 연결체는 '날개 달린 금서'다.
- 기술 이름: 사도의 부름 · 내리꽂는 광휘 · 천공의 파도.

## UI
- 상점: 처음에는 진열대와 안내만 보인다. 캡슐을 누르면 설명과 함께 전투원 목록이 열린다.
- 카드 열람 › 전술 각성: 각성 목록과 각성 카드 상세가 '고유 카드'와 같은 구조를 쓴다.
  - 머리띠, 가운데 큰 카드, 오른쪽 효과 패널, 좌우 화살표, 아래 버튼.
  - 상세 왼쪽에는 지금 카드를 함께 보여 준다.
