### 0.2 화면 변경에서 발견·수정한 문제

- 적 머리 위 정보를 추가하면서 스프라이트 시작 위치를 그대로 두면 예고와 얼굴이 겹친다. 데스크톱·가로 모바일 각각 예고 영역 아래로 스프라이트 공간을 확보했다.
- 준비 기술에도 대상 필드가 있다는 이유로 공격선을 그리면 실제 피해가 없는 행동을 공격으로 오인시킨다. 피해 또는 정신 효과가 있는 행동만 아군을 조준한다.
- 연출을 위해 전체 화면을 즉시 재생성하면 버림·드로우·변질의 출발점이 사라진다. 확정된 상태는 저장하되 기존 DOM에서 순서대로 재생한 뒤 새 손패를 배치한다.
- 신규 파트너 초상이 없을 때 연결된 전투원의 얼굴을 파트너 이름 옆에 재사용하면 인물이 혼동된다. 미완성 초상 대신 지원 문양을 표시한다.

### 0.3 회복과 직접 그린 VFX

- 회복 명령을 추가하는 것만으로는 도착과 재탐사 귀환의 자동 회복이 남는다. 두 진입 경로에서 복구와 회복 이벤트를 제거하고, 거점 저장도 부상 상태를 보존하도록 검증했다.
- 컷인 등장 직후 위치를 한 번만 읽으면 슬라이드 시작 위치에 효과가 그려져 화면 밖으로 나간다. Canvas 효과가 매 프레임 실제 스프라이트 위치를 따라가도록 수정하고 이동하는 앵커 회귀 검사를 추가했다.
- 브라우저의 배경 탭은 RAF 재생이 늦어질 수 있다. UI 검증은 실제 전투 탭을 전면에 놓고 효과의 중간 프레임과 정리까지 관찰한다.

### 0.4 카드 선택과 타격 피드백

- 카드 이미지 위에 별도 헤더가 겹치면 코스트가 가려진다. 공용 카드 코스트를 헤더보다 위에 놓고 손패·카탈로그 모두 실제 화면 확인.
- 키보드 카드 선택은 포인터 해제 경로를 거치지 않는다. 모든 유효한 행동 시작 시 카드 설명과 키 선택을 함께 비워 적 공격을 가리지 않도록 한다.
- 광역 공격의 전체 음량과 카메라 변위가 적 수에 비례하면 과해진다. 공격 사운드는 한 번 재생하고 카메라 충격은 합산 대신 최대 강도로 묶는다.

### 0.5 제공 원본 통합

- 전투/컷인/붕괴 역할을 먼저 분리한다. 전투 스프라이트를 초상이나 지원자 얼굴의 대용으로 쓰지 않는다. 제공된 파트너 그림을 실제 파트너 이름에 연결했다.
- 알파 bbox가 넓다는 이유만으로 저알파 찌꺼기라고 판단하지 않는다. 이 원본은 망토·머리·발이 경계에 닿는다. 추가 크롭 없이 발밑 좌표로 배치하고 공격선과 효과의 앵커도 함께 맞춘다.
- 캐릭터 교체는 현재 파티 이름만 바꾸면 중첩 거점/카드 UID/강화/보스 관측 대상/컷인 컬렉션이 깨진다. 실제 v1 엔진에서 만든 저장을 사용해 중첩 이관과 다음 행동까지 검증했다.
- 큰 신규 컷인은 첫 로드가 자동 종료 타이머보다 늦을 수 있다. 이미지 디코드 이후 타이머를 시작한다.
- 공유 프리뷰가 다른 프로젝트를 실행 중일 때 start만으로 대상이 바뀌지 않는 사례를 확인했다. 기존 프리뷰를 종료하고 대상 체크아웃으로 재시작한 뒤 문서 제목을 확인했다.

### 0.6 새 카드 틀과 장면 음악

- 전투용 카드 틀만 수정하면 선택/강화 카드에 과거의 높은 명시도 border가 남는다. 카탈로그와 비교창에도 같은 명시도로 테두리/코스트를 적용하고 양쪽 화면을 직접 확인했다.
- 음악 재생 제어를 SoundBank와 MusicDirector가 동시에 소유하면 탭 복귀/음소거 때 중복 시작할 수 있다. AudioContext와 혼합 버스는 SoundBank, HTMLAudioElement 재생과 장면 선택은 MusicDirector로 소유권을 정리했다.
- UI 이미지의 backgroundImage가 none이어도 자식 img의 src로 표시될 수 있다. 실제 렌더링 요소와 스크린샷을 확인한 뒤 결함 여부를 판단한다.

### 0.7 접힌 손패와 보상 정산

- 카드 전체를 translateY로 화면 밖으로 내리면 브라우저의 focus/scrollIntoView가 overflow:hidden인 게임 컨테이너까지 스크롤한다. 접힌 버튼 자체를 원래높이1/3로 줄이고 펼친 한 장만 전체높이로 확장한다. 게임 컨테이너는 overflow:clip으로 내부 스크롤을 금지한다.
- 새 초상은 정상 스탠딩과 동작 컷인의 얼굴 좌표가 다르다. 파트너마다 얼굴 중심을 확인하고 크롭 창과 개별 위치를 적용했다.
- 수령/넘어가기 버튼만 추가하고 승리 즉시 지급을 남겨두면 거절해도 보상을 받는다. 승리에서는 pending 보상만 만들고 정산을 한 번만 하도록 바꾸며, 구버전의 이미 지급된 보상은 재지급하지 않는다.
- 재탐사에서 새 이동 화면을 거쳐 거점에 돌아올 때 일반 최초도착 코드를 재사용하면 재시도횟수가 초기화된다. 귀환은 기존회복/재시도상태를 보존하는 별도 경로로 처리하고 검사했다.

### 0.8 · 튜토리얼 / 부상 / 테스트 페이지

- 튜토리얼 순서를 UI 강조만으로 막지 않는다. 엔진이 선택·발동·턴 종료·영입 게이트를 검증하고, 기존 경로 검사에는 명시적 tutorial:false를 사용한다. 새 기본 경로 검사를 별도로 추가한다.
- 눈 결손의 무작위 효과를 렌더 때 굴리지 않는다. 카드에 효과 키를 저장하고 비용 검증 실패 시 상태/RNG를 보존한다. live뿐 아니라 체크포인트도 이관한다.
- 카드 제거는 중복 카드의 고유 UID를 사용한다. 이름 전체 제거/편성 교체 복원/야영 체크포인트 덮기 회귀를 검사한다.
- 작은 화면 실제 검증에서 상태 창 탭이 화면 밖으로 밀리고 그리드의 %합+gap 때문에 가로 스크롤이 생겼다. flex 기반 하단 탭 고정과 minmax 비율열/낮은 높이 전용 크기로 수정했다.
- QA iframe의 렌더 순간 busy:true만 전달하면 외부 제어가 영구 잠긴다. 연출 종료의 busy:false도 전달하고 실제 능력 드래그 뒤 다음 프리셋 이동으로 확인한다.
- 테스트 페이지는 본편 localStorage와 분리하고 피드백 JSON에 테스트 상태를 포함한다. 자동 검증 외에 내보내기→삭제→불러오기→장면 재현을 실제 UI로 확인한다.

### 0.9 · 강조 영역과 정보 계층

- 펼치는 카드의 CSS transition 직후 한 번만 경계를 읽으면 강조 구멍이 카드 뒤에 남는다. 실제 경계를 짧게 추적하되 안내 버튼 DOM은 재생성하지 않아 클릭 도중 버튼이 사라지지 않게 한다.
- 모바일 안내 배치는 주 타깃뿐 아니라 AP 등 보조 강조 영역도 피한다. 전체 타깃의 상단/하단 후보를 비교하고 작은 화면에서 실제 비중첩을 확인한다.
- 여러 구멍을 evenodd로만 그리면 겹친 부분이 다시 어두워진다. 시각 마스크는 검정 구멍의 합집합으로 만들고 어두운 영역만 입력을 막는다.
- ‘부상 치료’와 ‘전부 회복’을 같은 것으로 취급하지 않는다. HP20/정신5/신체치료를 각각 검사하고 저장된 수치도 확인한다. 한 명 선택 정신 안정에 대상 없는 전체 회복 경로가 남지 않게 한다.
- 영입 응답 확인창은 저장에 남기고 확인하면 체크포인트의 응답도 함께 지워 재시작 때 중복 영입 안내가 나오지 않게 한다. 엔딩에서 이전 거점 복귀 시 이번 캠페인의 클리어 표식을 보존해 튜토리얼 직후 거점으로 오인하지 않는다.

### 0.10 · 타이틀의 계층과 실제 모바일 크기

- 원본 로고의 큰 투명 여백을 포함한 img 박스 크기만 조절하면 실제 글자 크기를 제어하기 어렵다. 원본은 그대로 두고 alpha 경계에 맞춘 CSS 컨테이너로 시각 크기를 잡는다.
- 타이틀까지 전투용 가상 해상도로 축소하면 휴대폰의 조작 글꼴이 지나치게 작아진다. 타이틀은 실제 viewport 배치, 게임 진입 시 원래 배율로 분리하고 양방향 전환을 실제 UI로 확인한다.
- opacity를 포함한 진입 애니메이션이 disabled의 낮은 opacity를 덮을 수 있다. 비활성 항목은 진입 애니메이션에서 제외하고 저장이 없는 상태도 직접 확인한다.
- 브랜드·배경·버튼의 광택을 각각 키우기보다 시각적 우선순위와 여백을 먼저 정한다. 타이틀 장면을 통째로 재생성하지 않고 메뉴 표시만 바꾸면 배경 이동/음악의 연결을 유지할 수 있다.

### 0.11 · 조작 스킵과 이야기 스킵을 분리

- 조작 튜토리얼을 건너뛴다는 뜻을 영입 대화까지 읽었다는 뜻으로 해석하지 않는다. 조작과 대화는 별도 액션·장면 조건을 사용한다. 기존에 잘못된 동작을 기대했던 테스트도 고치고, 두 구간의 대화 시작·저장 복원·명시적 대화 스킵을 추가로 검증한다.
- 공용 모달을 바꾸면 기존 화면의 내부 레이아웃과 포커스 스크롤까지 실제로 확인한다. 상태 창의 첫 카드에 포커스를 주면 내용이 아래로 이동한다. 닫기 버튼을 preventScroll로 포커스하고 Tab 이동은 열린 창에 유지한다.
- 기존 label의 flex-direction:column이 새 설정 행에도 남았다. 작은 가로 화면에서 확인한 뒤 방향을 명시해 음량 슬라이더가 행 안에 들어오도록 수정했다.
- 레거시 일러스트 감상 함수에 컷인에서만 정의하는 injured/part 변수가 복사돼 있었다. 감상 함수 범위만 수정하고, 실제 결손 컷인 경로는 보존한다. 공통 리팩터링 때 템플릿 전체를 무차별 치환하지 않는다.
- 긴 작업 중 실행 환경이 재시작될 수 있다. 소스 보존과 자격 증명 유효성을 먼저 확인하고, 없어진 스크린샷은 실제 UI에서 다시 캡처해 저장한다. 검수 이미지가 없는데 있다고 링크하지 않는다.

### 0.12 · 합류와 보상의 단계를 저장한다

- 파티 등록과 다음 전투 시작을 같은 액션에서 끝내면 합류 연출/대화가 전투에 가려진다. arrival → joinDialogue → 다음 튜토리얼/거점으로 나누고 커서를 저장한다. 조작 스킵, 요청 대화 스킵, 합류 대화 스킵은 각각의 범위만 이동한다.
- 대사는 데이터로 보존하고 스탠딩 숨김/기본 포즈/들썩임/흔들림을 별도 메타데이터로 처리한다. 기본 포즈 지시 뒤 파트너가 말해도 포즈가 다시 붕괴 상태로 돌아가지 않도록 앞선 지시도 확인한다.
- 모션 중에는 대화 열기를 막는 가시성 검사가 있다. careStart/careNext의 렌더 시 busy가 true면 열린 상태가 저장되어도 화면에는 나타나지 않는다. 모션 완료 경로에서 대화 재표시를 보장하고 실제 UI에서 시작/다음/끝을 모두 실행한다.
- 거점 사용 횟수를 ‘귀환할 때’ 초기화하면 무한 재탐사로 회복 제한을 우회한다. 거점 ID가 바뀔 때만 갱신하고, 출발한 거점 위치·사용 기록·체크포인트를 복원한다.
- 후보는 화면을 열 때 만들지 않는다. 사건/승리/거점 진입 때 RNG를 소비해 저장하고, 보상 수령과 강화 소비를 분리한다. 미수령 장비나 사용한 강화 후보를 중복 지급하지 않는다.
- 장비 이름만 저장하면 같은 전리품을 여러 명에게 복제 장착할 수 있다. 보유 수량과 장착 수량을 함께 검사한다. 구버전의 구매 장비도 보유 목록으로 보완한다.
- 새로 늘린 경로에서도 과거 상수 7로 진행/귀환하면 첫 거점으로 되돌아간다. 전체 경로 길이와 실제 출발 거점을 사용하고, 확장 전 지점 통과를 세 파티로 검사한다.
- 전투용 가상 해상도를 대화와 선택 장면에까지 적용하면 휴대폰의 글자가 작아진다. 새 장면은 실제 viewport로 배치하고 가로/세로를 직접 본다. 스크린샷 crop에는 DOM 사각형에 문서 스크롤 오프셋도 더해 아래 버튼이 잘린 검수 이미지를 남기지 않는다.
- 사건의 고정 정신 부담에 적 공격용 ‘의태’ 약점 태그를 붙이면 표시 +22보다 로엔이 더 큰 부담을 받는다. 사건 비용은 적 약점 태그를 사용하지 않고, 장비가 없는 각 캐릭터의 실제 증가량과 선택지 수치를 검사한다.

### 0.13 · 첨부 효과의 좌표와 수명을 연결한다

- 첨부 데모 카드가 내장된 효과에 이미지 인수를 생략하면 원래 손패 위에 예제 카드가 뜬다. 외곽 오오라는 투명 원본, 변환은 현재 실제 카드의 전후 텍스처를 명시한다.
- loop duration만 늘려서는 `_elapsed` 기반 노이즈가 느려지지 않는다. 화면 글리치의 진행률과 연속 시간 모두 같은 비율로 낮춘다. 짧은 전투 연출 설정과 붕괴 지속 조건을 혼동하지 않는다.
- 투명 상태 창에서 뒤의 전투 UI를 그대로 두면 글자와 버튼이 겹친다. 배경을 보존하고 게임 UI만 감상 중 숨긴 뒤 닫을 때 되돌린다.
- WebGL renderer 생성이 모든 브라우저에서 성공한다고 가정하지 않는다. 이 검수 브라우저에서는 실제로 실패했다. 같은 첨부 모델/숫자/물리를 투영하는 Canvas 경로를 마련하고, WebGL 경로를 화면 검수했다고 보고하지 않는다.
- 기존 fallback canvas를 넓은 주사위 무대에 width/height 100%로 늘리면 주사위가 납작해진다. 3D renderer는 컨테이너 종횡비를 갱신하고 정사각형 fallback은 object-fit으로 유지한다.
- 코드 수정 뒤 DOM이 남아 있다고 새 모듈까지 반영됐다고 가정하지 않는다. 명시적으로 다시 로드하고 QA 준비 메시지/버튼 활성화를 기다린 뒤 재현한다. 선택지 표기와 실제 option value도 DOM으로 확인한다.
- 적의 비공격 준비 동작을 모두 방어막으로 표시하면 실제로 없는 방어 효과를 암시한다. 현재 장막 여부를 검사하고 준비/충전 연출과 구분한다.

### 0.14 · 그림 단계와 실패 위험을 분리한다

- 극복 실패 때마다 기존 모션은 카드만 뒤집었다. 새 컷인 조건은 상태 전후의 시각 단계 상승으로 판정해 3→4회에 한 번만 재생한다. 기존 위험 강도 3을 세 번째 일러스트 단계로 연결하지 않는다.
- 새로 들어온 전신 PNG를 과거에 미리 잘라 둔 초상·카드 크롭에 그대로 넣으면 얼굴이 너무 작아지거나 카드 제목에 가려진다. 원본은 보존하고 각 캐릭터/단계의 얼굴 위치로 HUD·카드 표시 좌표를 따로 맞춘다. 실제 작은 손패를 펼쳐 표정과 설명을 확인한다.
- 컷인 한 경로만 교체하면 상태 창·대화·카드·도감에 폐기한 이미지가 남는다. 공용 단계 계산과 이미지 경로를 사용하고 모든 소비 지점을 확인한다. 배포에서 제거한 파일은 manifest의 활성 목록/파일 수/용량도 함께 갱신한다.
- 그림을 단계별로 도감에 넣어도 연출 버튼이 현재 실전 상태만 읽으면 다른 단계가 재생될 수 있다. 감상용 명시 단계와 실전 상태 기반 단계를 분리하고 감상으로 게임 상태를 수정하지 않는다.

## 0.15 — 붕괴 컷인과 스탠딩 교체 범위 오류

붕괴 일러스트 교체를 스탠딩·HUD 초상·카드·정신 안정 대화까지 확대 적용한 것은 잘못이었다. 새 1/2단계 이미지는 컷인만 교체한다. 기존 붕괴 스탠딩, 초상, 카드 원본을 복원하고 도감의 스탠딩은 기본/붕괴 두 탭을 유지한다. 같은 캐릭터라도 컷인·스탠딩·초상·카드는 별개 역할로 검증한다.

## 0.20 — 인계 UI 검수와 확인 방식

고정 디자인 캔버스 내부에 viewport 높이를 섞지 않는다. 80% 창 내부에 더 큰 최소 폭/viewport 높이를 다시 지정하지 않는다. 버튼이 DOM에 존재해도 부모의 pointer-events:none으로 클릭이 막힐 수 있으므로 직접 클릭 후 실제 결과를 확인한다. CSS 문자열 존재 검사는 비율과 클릭 가능성을 보장하지 않는다. 스크롤 목록 밖으로 합성 캔버스 효과가 새지 않게 클립한다. 연마 컷인의 장식 링이 불필요한 스크롤바를 만들지 않는지도 화면으로 확인한다.

## 0.21 — 화면 요소가 끝나는 시점과 공간을 실제로 확인한다

- WAAPI의 finished를 기다린 뒤 즉시 cancel하면 캐릭터가 효과 시작 전에 원위치로 튄다. 전진 프레임을 유지하고, 타격 VFX·피해 표시·복귀까지 하나의 수명으로 관리한다.
- 자유 전투 안내까지 busy 조건으로 숨기면 매 공격마다 깜빡인다. 조작을 가르치는 단계의 차단과 전투 내내 유지할 안내를 구분한다.
- 카드 설명 좌표는 접힌 카드나 화면 하단을 기준으로 정하지 않는다. 상승 중의 실제 카드 경계를 따라가며 용어 설명과 그림이 겹치지 않는지 확인한다.
- 스크롤바만 숨겨서는 메뉴를 고친 것이 아니다. 640×360에서 남은 최소 높이·간격 충돌로 안내가 잘렸으므로 네 버튼과 안내가 모두 패널 안에 들어가도록 크기를 조정했다.
- QA iframe이 바깥 패널에 가려진 상태에서 화면 끝 버튼을 클릭했다고 가정하지 않는다. 넓은 데스크톱 UI는 직접 게임 탭에서도 실행한다. 브라우저의 read-only DOM 평가에서는 performance/getAnimations 같은 API를 지원한다고 가정하지 않고 지원되는 DOM 경계·상태와 실제 화면을 검사한다.

## 0.25 — 화면 구조 보존과 이미지 역할 분리

- 사용자 제공 화면 구성은 배치 계약으로 취급한다. 톤 변경 요청만으로 탭/스탠딩/정보 구성을 바꾸지 않는다.
- 대화별 화면 배율과 부모 영역 높이가 달라지면 같은 스탠딩도 작아진다. 이미지 파일만 확대하기 전에 두 경로의 좌표계를 맞춘다.
- 캐릭터가 포함된 로비 배경에는 같은 캐릭터 스탠딩을 다시 겹치지 않는다.
- 각성 비교 화면에서 카드의 현재 효과를 확대 열람한 뒤 닫았을 때, 선택 중인 방향과 복귀할 부모 창이 보존되는지 실제 클릭으로 확인한다.
- 붕괴 컷인 교체는 스탠딩·HUD·카드에 전파하지 않는다. 단계 파일과 캐릭터별 명시 매핑으로 제한한다.
