# v0.18 UI 통일 · 로비 메뉴 수정 · 연마 카드 크기 고정 · 키라라 비례 스케일 · 카제나 전투원 열람창

## 변경 파일
- `dist/feedback-v18.css`, `dist/index.html`:
  - `body.in-lobby #header`를 완전히 숨기고 `.lobby-topbar`의 z-index/포인터를 보장해 로비 상단 메뉴 클릭 불가 수정.
  - `.refine-cutin-card .catalog-card.card-frame`을 기본 카탈로그 크기(`156×228`, 좁은 화면 `120×176`)로 고정하고 크기 변형 애니메이션 제거.
  - 상점 NPC(키라라)의 `65dvh` 스탠딩 + 화면 비례 대화상자(`clamp()` 및 가로/세로 미디어 쿼리) 판정을 로비 및 대화 스탠딩·대화창 전체에 적용.
  - 기존 모달·버튼·리스트·폰트 크기를 로비의 다크 택티컬(시안 좌측 강조선 + 얇은 보더) 스타일로 통일.
  - 카제나 전투원 열람 화면을 참고한 3단 레이아웃(`.czn-personnel`) 추가.
- `dist/app.js`, `dist/menu-ui.js`:
  - `header()`에서 로비 진입 시 이전 화면 body 클래스를 정리하도록 수정.
  - 로비 `전투원 · 파트너` 버튼을 전용 `lobbyPersonnel()`(좌측 로스터 / 중앙 전투원↔파트너 스탠딩 전환 / 우측 프로필·패시브·보유 카드·신체/정신 3탭)에 연결.
- `tests/feedback-v18.test.mjs`: v0.18 검증 테스트 추가 (총 121/121 통과).
