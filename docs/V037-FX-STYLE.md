# v0.37 — 이펙트 붓 규칙 (레퍼런스 13장 분석)

나모 님이 2026-11-28에 보낸 2D 이펙트 레퍼런스 13장(GIF 12, 정지 이미지 1)을 프레임 단위로 뜯어 본 결과와, 거기서 뽑은 그리기 규칙.
코드는 `dist/fx-brush.js`. 사이노 연출(`dist/judgment-vfx.js`)과 신규 전투원 연출(`dist/battle-vfx.js`)이 이 붓을 쓴다.
받은 그대로 고정된 이펙트 묶음(`dist/vendor/game-vfx-pack.js`, 해시 고정)은 건드리지 않았다.

## 공통점
1. **선은 칠한 모양이다.** 같은 굵기의 선은 하나도 없다. 몸통이 두껍고 양 끝은 바늘처럼 뾰족하거나(베기 초승달, 번개, 별 가시, 얼음 조각), 흐릿하게 꼬리를 끌며 사라진다(속도선, 휘두른 궤적의 뒤끝).
2. **흰 심지가 넓다.** 몸통 대부분이 흰색에 가깝고, 색은 가장자리 테두리와 바깥 빛무리에만 있다. 그래서 강한 에너지로 읽힌다.
3. **한 이펙트 = 한 색 + 흰색.** 보조색은 많아야 하나(초록 할퀴기의 주황, 보라 베기의 크림색 돌가루).
4. **고리는 붓으로 그렸다.** 한쪽이 두껍고 반대쪽이 가늘며 군데군데 끊긴다. 원근이 있는 고리는 앞쪽이 두껍다.
5. **실루엣이 날카롭고 고르지 않다.** 별 가시의 길이가 서로 다르고, 폭발 가장자리는 찢긴 듯 들쭉날쭉하다.
6. **박자: 순간 최대 → 잠깐 정지 → 꼬리부터 얇아짐 → 조각으로 흩어짐.** 대부분 12fps 안팎(2프레임씩 한 장)으로, 첫 1~2프레임에 가장 크게 터지고, 사라질 때는 통째로 투명해지지 않고 획이 가늘어지고 짧아지다가 점·조각으로 부서진다.

## 스타일
일본 애니메이션·모바일 액션 게임식 **손그림 2D 이펙트**(셀 애니메이션 작화). 검은 바탕 위의 가산 발광, 평평한 몇 단의 톤, 붓의 필압이 보이는 획.

## 왜 이 레퍼런스인가
- 기존 잔불 이펙트는 캔버스 기본 선(둥근 끝, 같은 굵기)이라 **형광 철사**처럼 보였다. 레퍼런스는 같은 빛이라도 **방향·속도·날카로움**이 획 모양 자체에 들어 있다.
- 원화가인 나모 님의 그림과 CZN의 화면은 손그림의 밀도로 서 있다. 이펙트도 같은 손맛이어야 일러스트와 따로 놀지 않는다.
- 끝이 뾰족한 획은 "베였다·꿰뚫렸다", 흐릿한 꼬리는 "빠르게 지나갔다"를 말없이 전달한다 — 카드 게임에서 타격감을 내는 가장 싼 방법이다.

## 붓 규칙 (fx-brush.js)
| 함수 | 쓰임 |
|---|---|
| `brushStroke(c, pts, {w, cols, head, tail, belly, core, glow, jag, ink})` | 모든 빛 획. 빛무리(옅은 겹 둘) → 색 몸통 → 흰 심지(몸통의 52%). `head`/`tail`은 `'sharp'`(굵기 0) 또는 `'soft'`(얇게 남고 투명해짐) |
| `crescent` / `arcPoints` | 베기·휘두른 궤적: 머리 뾰족, 꼬리 흐릿 |
| `brushRing` | 붓 고리: 앞쪽 두껍고 뒤쪽 가늘고 끊김 |
| `spikeStar` | 길이가 다른 네 갈래 가시 별(타격 순간) |
| `brushBolt` | 번개: 뾰족한 양 끝 + 마디마다 거친 굵기 |
| `inkStroke` | 사이노의 검은 먹 획(빛을 더하지 않음), 가장자리에 얇은 빛 |
| `fleck` | 진행 방향으로 늘어난 마름모 조각 — 흩어짐용 |

- 휴대전화를 위해 흐림 필터(shadowBlur)는 쓰지 않는다. 빛무리는 넓고 옅은 겹 두 장으로 낸다. 헤드리스 크롬에서 심판 연출 전 구간 프레임 중앙값 16.7ms(60fps).
- 점이 적은 획(직선 두 점)은 자동으로 잘게 나눠 굵기 모양이 보이게 한다.

## 적용한 곳
- 사이노: 번개 창·곁가지·수평 번개(뾰족), 먹 리본·먹 조각(머리 뾰족·꼬리 흐릿, 꼬리부터 깎여 사라짐), 바닥 고리·마디 고리(붓 고리), 타격 순간 가시 별, 불티(조각), 아누비스의 눈(붓 고리 + 뾰족한 눈꼬리, 끝에 가늘어지며 사라짐), 죄·명계 발동 번개, 결합 별빛.
- 신규 전투원 공용(battle-vfx.js): 번개 → `brushBolt`, 고리 → `brushRing`, 반짝임 → `spikeStar`, 불티 → `fleck`, 방사 광선은 양 끝이 뾰족한 마름모, 베기 궤적·속도선은 흰 심지를 넓힘.
- 추가(같은 날): 로엔 필살기 단검 촉(납작한 삼각형 → 꼬리 흐릿한 마름모), 일루가 등불 후광(같은 굵기 타원 두 줄 → 붓 고리), 보호막 하이라이트(같은 굵기 호 → 초승달).
- **클리어**: 화면을 덮는 큰 빛(반지름 420)과 방사 광선 18줄, 넓은 고리를 뺐다. 가로로 지나가는 가는 빛줄기 + 가시 별 하나 + 얇은 붓 고리 + 반짝임 22개(이전 70개)로 줄였고, 길이도 2초 → 1.5초.
- 모든 이펙트는 `/lab`(이펙트 시험장, docs/V037-VFX-LAB.md)에서 하나씩 볼 수 있다.
