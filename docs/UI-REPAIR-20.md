# 0.20 — Gemini 0.19 인계 및 화면 비율 정리

문제: 로비 고정 디자인 좌표와 내부 dvh/vw가 혼용되었고, 80% 창에 viewport 높이/최소 폭이 중첩되어 작은 화면에서 탭·본문이 밀렸다. 전투의 되돌리기/로그 버튼은 pointer-events:none인 상위 레이어를 상속해 실제 클릭이 되지 않았다. 전투원 열람의 신체 탭은 PARTS import가 누락되었다.

## 변경

- 사용자가 제공한 0.19의 기능을 0.15 저장소에 인계. engine.js는 제공된 0.19와 바이트 단위로 동일하며, 원정 기록·레이드·파트너 패시브·희귀 각성·전리품 장착·근거리 돌진·피해 예측·되돌리기 등 새 동작을 유지한다.
- sceneLayout으로 로비 1280×720 디자인 캔버스를 균일 배율로 맞추며, 로비 내부는 캔버스 기준 비율을 사용한다. 로비/전투/이야기 화면의 좌표 기준을 명시적으로 분리한다.
- feedback-v18/v19의 중복 덮어쓰기는 런타임에서 빼고 references/layout-history로 보관한다. interface.css에서 화면별 구조를 정의한다.
- 모달은 한 번만 viewport로 크기를 정하고 내부 아트/본문은 부모 패널을 따른다. 기본 80% 창, 작은 가로/세로는 탭과 조작 공간을 위해 90~92%로 확장한다. 제목 영역은 메뉴/기록만, 나머지는 접근 가능한 화면 이름과 닫기만 유지한다.
- 열람은 좌측 초상 레일/중앙 전투원·파트너 전환과 스탠딩/우측 세 탭. 파트너에서는 전용 지원 스킬·조건을 보여주고 전투원의 부상·정신 상태와 혼동하지 않게 한다.
- 상태창은 클릭 불가 스탠딩, 상태/보유 카드 두 탭, 하단 캐릭터 전환. 상점은 좌측 키라라/우측 구매 및 카드 제거, 편성은 교체 슬롯을 먼저 골라 해당 동료만 바꾼다.
- 정신 안정은 기존 붕괴 스탠딩과 사용자 대사를 유지한다. 새 단계별 붕괴 PNG는 여전히 컷인 전용이다.
- 카드 오오라는 스크롤 목록의 보이는 영역 안에서만 합성한다. 연마 컷인의 카드 크기/비율을 고정하고 장식 때문에 스크롤바가 생기지 않게 한다.
- 되돌리기/공격선 버튼은 적 정보 옆으로 이동하고 실제 클릭 영역을 보장한다. 전투 로그는 하단의 접을 수 있는 한 줄로 유지한다.
- QA에 메인 로비, 전투원·파트너 열람, 편성, 연마 컷인 정지 미리보기를 추가한다. 본편과 QA 저장은 분리된다.

## 검증

- 인계 직후 122개 검사 통과. 수정 후 125개 검사 통과. 이전 CSS 문자열 존재만 확인하던 검사는 배율/캔버스 포함 관계, 저장 보존, 모달 의미 구조, VFX 클리핑 검사로 교체했다.
- 실제 브라우저: 1280×720 / 844×390 / 640×360 / 390×740에서 열람·상태·상점·편성 총16개 조합의 화면 이탈 및 본문 가로 넘침 없음. 측정값은 layout-checks-20.json.
- 직접 조작: 신체/정신 탭, 파트너 전환 및 지원 스킬/조건 탭, 보유 카드 확대, 도감 적 목록, 메뉴→설정, 정신 안정 선택→기존 붕괴 스탠딩 대화 확인.
- 두 번째 동료 슬롯 일루가를 골라 야호다로 교체, 로엔/두린 유지 확인. 원정 기록 저장→로비→기록 기반 레이드 출격→정산 화면 확인.
- 일반 전투: 정확한 일격 사용 후 적 HP30→19, AP3→2, 손패 감소 확인. 수정한 되돌리기 버튼 클릭 후 HP30/AP3/카드 복원, 남은 횟수1 확인. 접힌 로그 클릭도 확인.
- Android/iOS 실기기, 사용자 장시간 플레이, 새 기능 전체 캠페인 밸런스 및 청취 평가는 미실시. 이 수정은 전반적인 게임 완성 판정이 아니다.
