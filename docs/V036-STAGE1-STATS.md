# v0.36 — 1단계: 능력치 · 데미지 공식 · 개인 피해 기록

기준: main 7e57459(v0.35.1) 위, 브랜치 `claude/v0.36-stats`. 기획 문서 4차 §6, 작업 순서 §0의 1단계.

## 들어간 것
- 전투원 능력치 `HERO_STATS`(engine.js): 체력·공격력·방어력·치명확률·치명피해. 기획 §6-6 초기값 그대로(신규 3인은 4단계에서 추가).
- 파티 HP = 출전 전투원(이탈 제외) 체력의 합. 동료가 합류하면 그 체력만큼 최대·현재 체력이 함께 오른다.
- 이탈: 이탈자의 최대 체력을 파티 최대에서 빼고, 현재 체력에서는 이탈자의 남은 몫(최대 체력 − 개인 누적 피해)만 뺀다.
- 데미지: `ATK × 카드 계수 × 치명 배율 × 100/(100+대상 DEF)` (취약 1.25배 유지). 치명은 전투원별 확률로 굴린다. 예측(카드 미리보기)은 치명 없이 계산한다.
- 적: 체력 ×10(공격력 평균에 맞춤), 방어력 10(보스 25), 공격 ×17 후 대상 전투원 DEF로 경감. 의도에 표시되는 숫자는 경감 후 실제 피해.
- 보호막: 전투원 개인 보호막. 공격받은 전투원의 보호막이 먼저 깎인다. 일루가의 방어 카드·필살기, 알베도 지원만 파티 전원(각자 1/3 비율). 화면의 ◇ 합계는 개인 보호막의 합.
- 개인 피해 기록: 맞은 전투원에게 `scar`(전투마다 0으로 시작 — 5단계 상흔 게이지의 바탕)와 `lost`(원정 누적, 회복 시 비율대로 감소)가 쌓인다.
- 카드 표기: `피해 100%`, `방어력 기반 본인 보호막 200%`, `방어력 기반 파티 전원 보호막 76%`, `최대 체력 기반 회복 4%`. 카드를 고르면(길게 누름 포함) 위 띠에 실제 수치(피해·치명 시 피해 또는 보호막)가 뜬다.
- 체력 회복·소모는 모두 최대 체력 비율: 거점 +30%, 야영 +20%, 사건·침식·불신도 %로 표기.
- 전투원 파일에 체력·공격력·방어력·치명 표시.
- 이전 세이브(공용 체력 100)는 불러올 때 비율을 유지한 채 새 체력으로 바뀐다. 레이드 보스 체력·기록도 10배.

## 내부 단위
카드의 `amount`는 '포인트'로 남겨 두었다(공격 1포인트 = ATK의 1/9, 보호막 1포인트 = DEF의 2/7). 4단계에서 카드 62종을 다시 정의할 때 기획 계수로 바꾼다.

## 밸런스 확인
자동 원정 테스트(세 조합)가 이전과 비슷한 재도전 횟수(0/0/1)로 엔딩까지 간다. 적 공격 배율 20에서는 5~9회, 17에서 0~1회.
