# v0.39 — 전투 배치: 발 기준 정렬 · 그림 크기 통일

## 발 기준
`CAST_FEET`(dist/cast-art.js): 그림마다 발 위치(너비 대비 0~1). 그림 맨 아래 3.5% 줄의 불투명 화소를 보고, 너비 1.5% 미만의 조각(떨어진 카드·리본 끝)은 빼고 양 끝의 가운데를 잰 값이다.
CSS(`cast-art.css`): `left = (.5 − foot-x) × cast-px × sprite-scale + nudge × cast-px` — 발이 전투원 자리(발판 고리) 가운데에 온다. 예전 식에는 배율이 빠져 있어 큰 그림일수록 어긋났다.
포즈를 바꿀 때(`motion.js pose`) 그 포즈의 발 위치와 배율로 함께 바꾼다. 붕괴 그림도 따로 잰 값을 쓴다.
새 그림을 넣으면 발 위치를 다시 재야 한다 (재는 스크립트는 이 문서 아래).

## 크기
`CAST_SPRITES[id].base = 대기 캔버스 너비 / 446`. 나모 님이 맞춰 둔 그림 크기(픽셀)를 그대로 살린다. 예전에는 모두 같은 키로 늘려서 야호다가 커지고 사이노가 작아졌다. 446은 7명 대기 그림 키의 평균이라, 평균 키는 예전과 같다.
이펙트 시험장도 같은 크기·발 위치로 세운다(`spriteFrame`).

## 자리 미세 조정 `CAST_NUDGE`
야호다 +0.07(오른쪽), 리니 −0.07, 사이노 −0.07(왼쪽). 단위는 전투원 칸 너비(PC 145px, 휴대전화 가로 115px).

## 키니치 분쇄 아쥬
분쇄 모드에서 `.ajaw-crush`가 키니치 뒤에 뜬다(너비 1.3칸, 발에서 0.66칸 위가 아래 끝). 추적 모드는 예전처럼 작은 아쥬. 모드 표시는 분쇄일 때 아쥬 머리 위로 올린다.

```python
# 발 위치 재기 (PIL + numpy)
a=np.array(Image.open(path).convert('RGBA'))[:,:,3]>160; ys=np.where(a.any(1))[0]; bot=ys[-1]; H=bot-ys[0]
band=a[int(bot-H*.035):bot+1]; cols=band.sum(0); keep=np.where(cols>=max(2,band.shape[0]*.3))[0]
# keep을 연속 구간으로 나누고 너비 1.5% 미만 구간을 버린 뒤 (첫 구간 시작 + 끝 구간 끝)/2/너비
```
