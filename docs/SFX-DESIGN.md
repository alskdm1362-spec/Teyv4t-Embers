# 직접 작성한 효과음 · 0.4

`dist/assets/audio/sfx`의 27개 WAV는 이 프로젝트를 위해 직접 합성한 원본이다. 외부 녹음이나 다운로드한 샘플을 입력으로 사용하지 않았다. 창·베기·마법·방어·심연·천공·종이·회복의 음색이 같은 사인파 비프음을 반복하지 않도록, 필터 노이즈·짧은 충격·금속의 비정수 배음·저음 몸통·상승 잔향을 서로 다른 조합으로 배치했다.

## 검색한 공식 참고 자료

- Kenney Impact Sounds: https://kenney.nl/assets/impact-sounds — impact/foley 분류, 공식 페이지에 Creative Commons CC0 표기.
- Kenney RPG Audio: https://kenney.nl/assets/rpg-audio — foley/RPG/weapon 분류, 공식 페이지에 Creative Commons CC0 표기.
- Kenney Interface Sounds: https://kenney.nl/assets/interface-sounds — interface/click/button 분류, 공식 페이지에 Creative Commons CC0 표기.
- Kenney 지원·라이선스 설명: https://kenney.nl/support — asset 페이지 자료의 CC0 사용 범위 및 선택적 크레딧 안내.

공식 페이지의 검색 결과 본문을 두 검색 엔진으로 확인했다. 페이지를 직접 여는 요청은 수집 환경의 restricted URL 응답으로 실패했다. 위 자료는 효과음 종류를 분류하는 검색 참고 자료이며, 원본 클립을 청취·분석했다거나 게임에 수록했다는 의미가 아니다. 현재 WAV는 모두 아래 DSP 레시피로 새로 작성한 것이므로 Kenney 원본 파일의 재배포·변형 사용은 없다.

## 파일·믹싱 기준

- 24,000Hz, mono, signed 16-bit PCM WAV. 총 417,828 bytes(약 408KiB), 20개 논리 키 / 27개 파일.
- 최장 victory 0.92초. 일반 명중·종이는 0.065–0.48초, 회복 0.86초.
- 파일별 최대 피크는 -4.73dBFS 이하. 모든 파일의 첫·마지막 샘플은 0이며 PCM 범위 밖 샘플은 없다.
- `manifest.json`의 `assets[key]`는 변주 배열이며 각 항목에 src, duration, peakDbFS, rmsDbFS, bytes, sha256이 있다.
- 저음과 금속/노이즈 층은 파일에 포함된다. 브라우저에서 별도 원음들을 또 겹치지 않는다. windup+hit의 두 역할만 필요한 시점에 나누어 재생한다.
- 광역 공격에서 대상 수만큼 같은 타격을 동일 시각에 크게 중첩하면 위상이 더해질 수 있다. 광역 명중은 1회 중심 레이어 + 작은 대상별 변주, 음량 상한과 동시 재생 제한을 사용한다.
- 일반 버튼·종이 소리는 전투 타격보다 작게, 회복/승리는 BGM과 싸우지 않게 둔다. 마스터·BGM·SFX·UI 버스는 루트 오디오 모듈에서 제어한다.

## 재생성·검증 한계

`python scripts/build-sfx.py`로 같은 deterministic 파형과 manifest를 다시 만든다. NumPy/SciPy의 기존 설치 환경을 사용하며 별도 설치나 외부 입력 파일은 없다. 모든 WAV 헤더, 길이, 피크, RMS, 중복 해시, 시작/끝 0, DC 성분을 검사했다.

현재 도구 환경에서 헤드폰·스피커를 통한 실제 청취 평가는 하지 않았다. 수치 검사만으로 청감이 완성됐다고 주장하지 않으며, 브라우저의 이벤트 연결·믹싱 및 사용자 실기기 청취를 통해 강도와 음색을 최종 조정해야 한다.
