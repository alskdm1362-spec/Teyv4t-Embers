# v0.36 — 2단계: 카드 용어 체계

기준: `claude/v0.36-stats`(1단계) 위, 브랜치 `claude/v0.36-terms`. 기획 4차 §9, 확정 기록(신속 미도입).

## 규칙 키워드 (dist/keywords.js, engine.js)
카드 정의의 `keywords` 배열(최대 2개 권장)과 기존 `exhaust`로 붙는다. 카드 설명 맨 앞에 `보존 · 소멸.`처럼 이름이 찍히고, 고르면 위 띠에 정의가 뜬다.

| 키워드 | 동작 |
|---|---|
| 소멸 | 기존 그대로 |
| 증발 | 턴 종료 시 손에 있으면 소멸 더미로 |
| 사용 불가 | 사용 시도를 거절 |
| 유일 | 표시만(복제 보상이 생기면 제외 대상) |
| 보존 | 턴 종료 때 손에 남고, 보존한 횟수가 붙는다. `retainBonus`가 있으면 그만큼 계수가 오른다(「보존:」) |
| 회수 | 무덤(버린 카드)으로 갈 때 한 번 손으로 돌아온다 |
| 종극 | 사용 후 턴이 끝난다 |
| 개전 | 전투 시작 때 뽑을 카드 맨 위 |
| 주도 | 턴 시작 50% 확률로 비용 -1, 다른 카드를 먼저 쓰면 사라짐 |
| 연계 | 손에 있을 때 다른 전투원이 카드(또는 공격 카드)를 쓰면 `chain` 효과가 턴당 1회 발동 |
| 감응 | 뽑히면 `sense` 효과 발동(AP·보호막·균열·드로우) |

신속은 넣지 않았다(적 행동 카운트가 없음).

## 잔불 고유 용어
- 균열: 받는 피해 +8% × 스택(최대 5), 턴 종료 때 1 감소. 기존 '취약'을 모두 균열로 바꿨다(취약 1턴 → 균열 2, 타다 남은 불티는 균열 1, 야호다 지원 균열 2).
- 위축: 적의 다음 공격 피해 -25%(`e.wither` 턴 수). 카드 효과 `wither`.
- 되비춤: 보호막으로 공격을 전부 막으면 공격자에게 방어력 기반 반격. 기존 '방어 성공 시 다음 공격 추가 타격'을 되비춤으로 바꿨다(일루가 반격 카드·필살기 포함).
- 추적흔·조준점·태양화·상흔: 용어 사전에만 올렸다. 동작은 4단계(캐릭터)·5단계(부상)에서.
- 이름 정리: 흑염의 잔향 → 타다 남은 불티, 악몽의 잔향 → 악몽의 찌꺼기.

## 손패 10장
손패가 10장이면 드로우·생성·회수가 멈춘다(기존 상한을 규칙으로 표기). 전투 화면 오른쪽에 `손패 N/10`, 9장 이상이면 주황 경고색.
