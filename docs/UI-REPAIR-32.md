# v0.32 — 셀 애니메이션풍 전투 이펙트

기준: main(PR #8 병합) 위, 브랜치 `claude/v0.32`.

## 방향
사용자가 보내 준 2D 프레임 애니메이션 VFX 레퍼런스(Behance, Ivan Boyko 작업 3건)를 참고했다. 이미지는 가져오지 않았고 결만 따랐다.
- 단색 덩어리: 어두운 테두리 → 색 → 밝은 색 → 흰 심지, 2~4단계.
- 날카로운 끝으로 가늘어지는 궤적, 갈라져 흩어지는 별 모양 타격.
- 흰 번개 실선, 부드러운 번짐은 도형 바깥에만.
- 초당 18장으로 끊어 그리고, 장마다 모양이 조금씩 흔들려 손그림 같은 맛을 낸다.
- 픽셀(도트) 방식은 사용자 요청으로 쓰지 않는다.

## 구현
- `dist/cel-vfx.js`: 화면 전체 캔버스 하나에 코드로 그린다.
  - `celPlan(kind, options)`이 게임 이펙트 종류를 그릴 단계 목록으로 바꾼다.
  - `CelVFX.play()`는 타격 순간에 Promise를 끝내고, 이펙트는 남은 시간 동안 혼자 재생한다.
  - `still()`은 QA용 정지 프레임을 그린다.
- `supplied-vfx.js`: `celPlan`이 있는 종류는 셀 이펙트로, 나머지(승리, 컷인, 불꽃 회복, 시간 되감기 등)는 기존 공급 팩으로 보낸다.
- 이펙트 종류와 색:
  - 로엔 얼음빛: 찌르기 궤적 + 4갈래 섬광 / 필살기에 큰 타격과 초승달 베기.
  - 두린 보라·분홍: 구체(흰 리본이 휘감고 흰 번개) / 필살기는 큰 구체가 터진다.
  - 일루가 금빛: 초승달 베기 / 필살기는 하늘에서 내리꽂는 빛기둥과 바닥 충격.
  - 야호다 분홍·청록: 올려 차는 초승달 / 필살기는 번개 줄기 + 큰 타격.
  - 지원: 바르카 청록 베기, 플린스 보라 찌르기, 네페르 독 튀김.
  - 공통: 방어막 거품, 막기, 적 타격(심연 자홍 / 천공 금빛), 적의 기 모으기, 적 소멸 연기, 회복·집중 상승.
