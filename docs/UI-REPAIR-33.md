# v0.33 — 자연스러운 전투 이펙트와 정신 붕괴 컷인

기준: main(PR #9 병합) 위, 브랜치 `claude/v0.33`. v0.32의 셀 이펙트(cel-vfx.js)는 사용자 피드백("허접하다")에 따라 폐기했다.

## 전투 이펙트 (dist/battle-vfx.js)
끊지 않는 연속 시간으로 그린다. 들어가는 요소:
- 가산 합성 빛과 입자(감쇠·중력)
- 움직임이 번진 줄기, 양 끝이 가는 그라데이션 베기 궤적
- 불꽃 혀, 번개, 십자 반짝임
- 연기·불꽃 등 겹쳐 그려야 하는 것은 일반 합성으로 먼저 그리고, 빛은 그 위에 가산한다.

| 대상 | 이펙트 |
|---|---|
| 로엔 | 창 찌르기(얼음빛 줄기, 섬광, 얼음 파편) / 필살기: 단검 3자루 투척 |
| 두린 | 검은·붉은 불꽃(검은 불꽃 혀 위에 붉은 불꽃, 잿불 불티) / 필살기: 더 큰 불기둥과 충격파 |
| 일루가 | 금빛 창 베기 / 방어: 등불의 빛이 퍼지며 아군을 감싸는 후광 / 필살기: 더 큰 베기 |
| 야호다 | 분홍 발차기 궤적과 타격 / 필살기: 3연타 |
| 바르카 | 청록 바람과 함께하는 대검 베기 |
| 플린스 | 남색 낙뢰 2회 |
| 네페르 | 어두운 녹색 발차기와 독 안개 |
| 강화(집중·사기·회복) | 반짝! 십자 반짝임 |
| 승리 | 금빛 광선, 큰 고리, 흩날리는 반짝임 |
| 생명의 불꽃 | 따뜻한 불꽃 혀가 피어오르고 회복 반짝임이 올라감 |

컷인 안의 이펙트는 위쪽 레이어(z 80)에, 전장 이펙트는 아래쪽 레이어(z 47)에 그린다.

## 정신 붕괴 컷인 (dist/collapse-scene.js)
사용자가 보낸 카제나 붕괴 컷인 스크린샷을 참고했다. 붕괴 그림은 투명 배경 컷아웃이므로, 효과를 캐릭터 **뒤**에 깐다.
- 절망: 캐릭터 뒤 유리판에 금이 가고, 뒤에서 새어 나오는 빛이 금 사이로 퍼진다. 조각이 서서히 벌어지고 파편이 떠다닌다(일부는 앞쪽, 흐림).
- 공황: 마른 붓 느낌의 소용돌이 여럿이 서로 다른 속도로 돈다.
- 폭주: 캐릭터 뒤 검은 구멍, 붉은 동심원, 가로 레이저, 밖으로 달리는 붉은 줄기.
- 불신: 녹색 안개 위로 가시 사슬이 지나가고, 앞쪽에 흐린 사슬이 걸친다.

일러스트 톤 보정:
- 테마색 림라이트(drop-shadow)와 대비를 살짝 올렸다.
- 배경은 어두운 바닥, 테마색 하나, 캐릭터 뒤 광원, 비네트로 구성해 그림이 먼저 보이게 했다.

붕괴 이름은 왼쪽 아래에 크게, 테마색 발광과 기울임으로 표시한다. 절망은 금 간 글자, 폭주는 떨린다.
1·2단계 모두 같은 테마를 쓰고, 2단계는 요소 수가 늘어난다. 기존의 화면 앞 유리 깨짐(glass-shatter.js)은 이 연출로 대체했다.
