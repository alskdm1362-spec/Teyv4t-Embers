# v0.39 — QA 화면 리디자인

- 위쪽 탭: 게임 · 이펙트 시험장 · 피드백(미검토/전체 수). 주소 `#lab`, `#lab/그룹/이름`, `#feedback`.
- 게임 탭 왼쪽 조작판: ① 편성(초상 칩, 누른 순서대로 셋, 첫째가 「전투원」) ② 장면(묶음 + 찾기, 누르면 바로 불러옴) ③ 상태 조정(접힘) ④ 연출 미리보기.
- 고친 것
  - 편성: 예전에는 모집 순서 때문에 키니치·리니·사이노를 동료로 고를 수 없었고, 고른 동료가 조용히 바뀌었다. 이제 `qaFixture`가 고른 셋으로 바로 편성한다.
  - 정신 안정 대화·키라라 상점·획득 장비 장착·실명 카드 연소·적 방어막은 필요한 장면이 아니면 "먼저 불러오세요"만 띄웠다. 이제 알맞은 장면을 불러온 뒤 연다(↻ 표시).
  - 예전 묶음 이펙트 미리보기(첨부 공격·아군 방어막)는 이펙트 시험장으로 옮겼다.
- 휴대전화(좁은 화면)에서는 게임 미리보기가 맨 위, 조작판이 그 아래.
