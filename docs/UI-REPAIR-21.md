# 0.21 — 17개 화면·전투 피드백 반영

## 변경

1. 튜토리얼 딤을 .85에서 .70으로 낮췄다. 초기 두 카드를 소진해야 AP·턴 종료를 함께 강조한다. 다음 턴의 AP 3 설명은 확인 후 자유 전투로 넘어간다. 자유 전투 안내는 기존 y=75를 유지하고 수평 중앙에 두며 전투 연출 중 제거하지 않는다.
2. 용어 설명은 실제 올라오는 카드의 DOM 경계를 따라 카드 위 12px에 배치한다. 화면 크기가 바뀌어도 갱신한다.
3. AP를 battle 직접 자식으로 옮겨 하단에 고정한다. 카드와 독립된 좌표를 사용한다.
4. 파티·적의 배치 영역을 8% 위로 옮긴다. 해당 영역의 비율이므로 전투 화면 높이로는 약 5~6%다.
5. 공통 VFX 재생 배율을 1.35로 올린다. 전체 화면 붕괴 유리와 카드 원본 합성은 기존 프레임을 유지한다.
6. 돌진의 마지막 프레임을 유지한다. VFX와 피해 숫자, 처치 연출이 끝난 다음 복귀 애니메이션을 재생하고 두 유지 효과를 함께 해제한다.
7. 모든 플레이 단계의 헤더는 공용 체력·정신 HUD와 메뉴만 사용한다. 기존 타이틀 브랜드 바, 기록·전투원 중복 버튼과 하단 개발판 바를 제거한다.
8. 메뉴의 높이·본문을 부모 패널에 맞춘다. 640×360에서 남아 있던 버튼 간격과 최소 높이 충돌도 수정해 안내와 네 버튼을 모두 보여준다.
9. 상태·메뉴·상점·적 정보는 rgba(3,8,16,.70), backdrop-filter blur(14px)를 적용한다.
10. 로비는 1280×720 기준 캔버스의 중앙 스탠딩, 좌측 진행 정보, 우측 네 메뉴로 구성한다. 작은 화면은 기존 균일 배율 원칙을 유지한다.
11. 목록/보유 카드에서는 캐릭터 뱃지를 빼며, 전투 손패의 캐릭터 구분은 유지한다.
12. 도감은 스탠딩 레일과 하단 선택 강조, 상태는 개인 색과 간결한 구획을 사용한다. 기존 기본/붕괴 스탠딩과 컷인 연결은 변경하지 않는다.
13. 장비는 무기/장신구 구분, 장착 중인 장비, 새 장비 효과와 등급, 대상별 기존 장비를 보여준다. 상점은 구매·장착과 보유 장비 장착을 구분한다.
14. 사건은 파티가 있는 상단 무대와 카드 자리의 하단 선택지 2~3개로 구성한다. 일반 보상은 무료/체력 6/정신 부담 7 중 저장된 난수로 비용을 정한다. 엘리트 장비·40 이상 모라 선택은 원래의 큰 대가를 유지한다. 불러오기나 화면 열람으로 다시 뽑지 않는다.
15. 모든 적의 모습·이름·기본 정보·기술·특징을 공용 enemy-guide에서 제공한다. 전투 중에는 다음 행동의 실제 대상과 피해·정신 수치도 표시한다.
16. 펼친 전투 기록은 화면 좌측 중앙에 고정한다. 접힌 최근 한 줄 기록으로 열고 닫는다.
17. 전투원은 HUD 초상으로 열람한다. 기존 상단 기록·전투원 버튼은 없다.

## 직접 실행 확인

- 844×390: 튜토리얼 두 장 사용 → AP 0 → 턴 종료 → AP 3 설명 → 자유 전투 → 추가 공격. 공격 직후에도 자유 전투 안내가 남는 것을 확인했다. 조준 카드를 펼쳐 소멸 설명이 카드 위에 표시되는 것을 확인했다.
- 일반 전투: 로엔 일격으로 수계 사냥개 HP30→19, AP3→2. 일루가 견제, 되돌리기, 견제 재사용 후 HP19→10, AP2→1. 실제 타격 중 일루가의 돌진 클래스와 적 앞 위치(x411, 원위치 영역 x264)를 확인했다. 최종 위치 복귀도 화면으로 확인했다.
- 전투 기록 펼침: 좌측 중앙 배치. 적 정보 수계 사냥개→황야 배회자 전환, 실제 공격 예고와 기술 목록 확인.
- 상태→보유 카드: 캐릭터 뱃지가 없는 카드 원본과 확대 열람 유지. 도감 스탠딩 레일 확인.
- 상점에서 정찰용 무기 구매 후 로엔의 무기 칸 반영 확인. 전리품 장착 화면에서 잔불의 창과 세 동료의 기존 장비가 보이며 로엔에게 장착되는 것을 확인했다.
- 메뉴: 640×360 / 844×390 / 390×740에서 내부 높이 넘침 0. 네 버튼이 패널 안에 있다. 데스크톱 직접 게임 탭 1363×936에서도 내부 높이 넘침 0. QA의 1280×720 iframe은 바깥 도구 패널에서 수평 스크롤되므로 데스크톱 메뉴 조작은 직접 게임 탭에서 검사했다.
- 상태창 배경의 실제 계산값 rgba(3,8,16,0.7), blur(14px) 확인. 640×360에서도 캐릭터 선택·카드 탭·신체 표시는 접근 가능하다.
- 새 로비와 사건을 실제 렌더링해 스크린샷으로 기록했다. QA 본편 저장 분리는 유지한다.

## 자동 검사와 남은 확인

129개 회귀 검사 통과. 새 검사는 다음 턴 안내의 저장·차단, 일반/고급 사건 비용과 저장 보존, 전 적 기술 목록, VFX와 피해 피드백이 끝나기 전 돌진 유지 동작을 검증한다.

Android/iOS 실기기 터치, 사용자 장시간 플레이, 전체 원정 밸런스와 실제 기기 프레임 평가는 남아 있다. 세로 모드의 전투/로비는 기존 가로 디자인 캔버스를 축소한 형태이며, 권장 플레이는 가로 화면이다. 이번 반영을 게임 전체 완성 판정으로 사용하지 않는다.
