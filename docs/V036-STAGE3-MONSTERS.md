# v0.36 — 3단계: 몬스터 기믹 단순화 · 정신부담 조건

기준: `claude/v0.36-terms`(2단계) 위, 브랜치 `claude/v0.36-monsters`. 기획 4차 §8, §7-4.

## 몬스터 (dist/enemy-patterns.js)
- 외형·이름·배치는 그대로. 행동은 `ENEMY_CYCLES`의 순서표 하나로 정한다(엔진과 적 정보 화면이 같은 표를 쓴다).
- 일반 몬스터: 기믹 없는 공격만. 수치와 순서로 차이를 낸다.
- 잔향 삭제: 마디벌레·추적자는 한 번 쓰러지면 끝. 침식(진드기)·장막(부유체·포식자·고치)·관측(관측자)·별(파수)·연결체 소환도 원정에서는 빠졌다.
- 정예전(정예 칸·도전): `mental` 표시가 된 동작이 정신 공격이 된다(정신 부담 +20, 보호막과 무관).
- 원정 보스(천의 눈·관측자·파수): 세 동작을 정해진 순서로 반복, 세 번째 또는 두 번째가 정신 공격(+30). 적 정보 아래에 `다음 · 동작 · 피해`로 다음 행동을 보여 준다.
- 레이드 보스 천공의 사도·케루빔은 기존 기믹(장막·금서 소환)을 그대로 쓴다. 레이드 모드에서만 옛 행동 규칙이 돈다.

## 정신부담 (§7-4)
- 정신력 1단계 = 정신부담 게이지 10으로 읽었다(게이지 100 = 10단계).
- 보호막으로 다 막지 못해 HP 피해를 받으면 1회당 +10, 전투원당 턴당 최대 +20.
- 정신 공격(정예 +20, 보스 +30)은 보호막과 무관. 일반 몬스터는 정신 공격을 하지 않는다.
- 피해량에 비례하던 정신부담(`STRESS_PER_DAMAGE`)은 더 쓰지 않는다.
