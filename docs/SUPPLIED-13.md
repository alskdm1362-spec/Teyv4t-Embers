# 0.13 · 첨부 VFX / 주사위와 투명 감상 화면

2026-11-23. 전투 수치·보상 확률·게임 RNG·대화·세이브 구조는 유지한다. 첨부 VFX 원본은 `dist/vendor/game-vfx-pack.js`, 첨부 주사위 HTML 원본은 `references/supplied/`에 보존한다. 파일 해시는 같은 폴더의 `provenance.json`에 기록했다. Three r128과 MIT 라이선스는 로컬 포함하며 런타임 CDN 요청은 없다.

파트너 지원도 대응 전투원의 색 계열을 사용한다. 공용 보호막을 주는 전투원의 색으로 아군 전원에게 연출한다. 피격 시 아군에 적 전용 방어막을 쓰지 않는다. 실제 장막을 가진 적의 전투 진입/방어 동작과 장막 파괴에만 방어막을 표시한다. 장막이 없는 준비 동작은 기존 충전 연출을 쓴다. 카드 프레임의 기존 캐릭터 색은 바꾸지 않는다.

기존 공격/회복 효과음을 유지하고 발광 강도·짧은 연출·흔들림 설정을 따른다. hitImpact는 적의 직접 타격, stageClear는 승리, warmFlameHeal은 거점의 신체 회복 행동, clockRewind는 거점 재시작에 연결한다. 별도 규칙이 없는 기존 충전·소멸 효과는 원래 전용 연출을 유지한다.

## 붕괴와 실명

- 유리 파편: SVG 유리 대신 첨부 screenShatter. 컷인 내부 z-index 0, 이미지 1, 설명 3. canvas CSS opacity 0.26으로 아트 뒤에 둔다.
- 카드 오오라: 실제 DOM 붕괴 카드 위에 cardOminousAura의 외곽 연기·촉수를 사용한다. 투명 cardImgA를 전달해 라이브러리 데모 카드가 나타나거나 실제 글자를 가리지 않도록 했다. 카드의 검은 외곽 그림자도 유지한다.
- 화면 글리치: 현재 파티의 한 명이라도 붕괴 중일 때만 지속. 벤치 인원은 제외하고 이탈한 현재 파티원은 포함한다. _elapsed와 progress 모두 0.28배 속도, edgeDepth 0.1, burstFreq 0.08. 빠른 진행과 독립이며 기기 동작 줄이기에서는 생략한다. 숨겨진 탭에서는 중지하고 돌아오면 현재 상태로 재개한다.
- 실명 변환: cardBurnTransition에 현재 카드의 그림·이름·코스트·설명으로 만든 두 텍스처를 전달한다. 일반→실명, 눈 결손이 남은 붕괴 회복→실명에 재생. 이미 실명인 카드의 드로우/세이브 로드에는 반복하지 않는다. 붕괴 중에는 붕괴 카드가 우선한다.
- 지속 canvas는 한 장만 사용하고 상태 갱신 때 중복을 제거한다. 마지막 붕괴 회복 및 타이틀 이동 때 지속 효과를 없앤다. 전투 종료 시 transient effect의 promise/canvas/RAF를 정리한다.

## 주사위

첨부 PolyhedralDiceEngine에서 모델, UV 숫자 배치, 바닥 튕김, 정면 정렬을 추출했다. 카메라는 16으로 조정해 작은 주사위를 보여 준다. 실제 판정 결과를 targetValue로 전달하고, 물리는 판정을 다시 굴리지 않는다. 기존 판정 사건과 QA 판정 미리보기에 적용한다. 현재 확장 사건의 고정 이득·대가를 주사위 판정으로 바꾸지는 않는다.

WebGL 사용 가능 시 원본 조명과 그림자를 사용한다. WebGL을 만들 수 없을 때도 같은 모델·텍스처·물리를 Canvas에 투영하는 호환 렌더러를 사용한다. 이것도 실패할 때만 기존 2D 주사위로 대체한다. 소리는 기존 음량 설정을 거치고, 모달을 닫거나 바꾸면 RAF·창 리사이즈 핸들러·geometry·texture·material·renderer/context를 해제한다. 빠른 결과 확인도 확정된 면을 보여 준다.

## 감상 UI

상태 창의 스탠딩 영역은 투명하다. 상태 창/확대 감상 중에는 배경만 남기고 원래 전투 UI를 숨겨 겹치는 글자와 버튼을 없앤다. 카드·일러스트 확대에는 프레임/제목창/불투명 배경 없이 대상과 닫기만 표시한다. 스탠딩은 기본/붕괴 탭을 둔다. 붕괴 아트가 없는 파트너에게는 탭을 만들지 않는다. 확대를 닫으면 이전 상태 창/도감 상세로 돌아간다.

도감의 전투/붕괴 전투 스프라이트 항목은 제거했다. 확대/연출 버튼은 가로 정렬이다. 상태 창 스탠딩을 누르면 동일한 확대 화면으로 연결한다.

## 검증

- Node 101개 검사 통과. 6종 다면체의 모든 면 방향, d20 결과 1~20 각각의 물리 정지/완료 콜백 1회, 캐릭터/적 방어막 분리, 새 실명 상태만 연소, 붕괴 지속 canvas 생명주기, 도감 상태 아트와 원본 해시 포함.
- 실제 브라우저: 기본 전투의 공격·방어·적 턴·드로우, 바르카 지원→두린 광역→일루가 마무리→승리/리워드 화면까지 플레이.
- QA 상태 변화 연출: 눈 결손 컷인→실제 손패 두 장 연소→실명 이름/코스트/설명 전환→busy 해제, 마지막 잔류 canvas 0 확인.
- 붕괴 2명 중 1명 회복 시 glitch 유지, 마지막 회복 시 canvas 0 확인.
- 네 캐릭터 공격 색, 검은/보랏빛 카드 오오라, 유리 z-index/opacity, 카드 확대, 기본/붕괴 전환, 파트너 기본 단독, 닫기/Esc 복귀, 640px 도감 확대/연출 버튼의 동일 y좌표 확인.
- 844×390 상태 화면, 390×740 스탠딩 감상, 640×360 주사위 정면 17 결과를 직접 확인했다. 캡처는 `docs/screenshots/embers-13-*.jpg`.

이 테스트 브라우저는 WebGL context를 제공하지 않으므로 같은 물리를 쓰는 Canvas 호환 렌더링을 화면 검수했다. WebGL 조명/그림자와 실제 안드로이드 터치·GPU 성능은 실기기에서 추가 확인이 필요하다. 전체 장기 캠페인을 사람이 다시 끝까지 플레이했다는 의미는 아니다.
