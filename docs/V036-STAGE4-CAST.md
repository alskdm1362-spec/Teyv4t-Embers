## 구조
- `dist/cards-v2.js`: 카드 62종(덱 카드 56 + 특수·생성 6)과 분기 224개가 데이터로 들어 있다. 카드는 `ops`(효과 목록)로, 분기는 바뀌는 항목만 적는다. 줄 성격은 A 안정 / B 자원 / C 변형 / D 빌드.
- `engine.js`의 `runOps`가 효과를 실행한다. `cardInfoV2`가 비용·키워드·설명·실제 수치를 만든다. 이전 카드 정의(awakening.js의 NEW_CARDS, card-insights.js의 분기표)는 이 표로 대체했다.
- `dist/cast36.js` + `dist/assets/cast36/`: 키니치·리니·사이노와 파트너 4인의 그림, 결손 그림, 로엔8·9 / 두린8·9 / 야호다8 추가 카드 그림(자체 manifest). 기존 그림 폴더와 manifest는 그대로다.
- 그림 배정은 기획 표의 번호 그대로(`art`).

## 전투원별 구현
- 로엔: 서리 파편(사용 불가, 손패 최대 3). 버려지면(선택 버리기·쇄빙·턴 종료·커튼콜 등) 마지막 대상에게 추가공격 30% 후 소멸. 바르카: 한 번에 3장이면 적 전체, 단일이면 ×1.3.
- 두린: 협공(다른 전투원의 공격 카드에 50%, 전체 25%, 턴당 3회). 알베도: 협공마다 태양화 1, 3이면 상한 +1과 다음 협공에 방어력 기반 60% 추가. 공명하는 손은 손에 있을 때 연계로 발동.
- 야호다: 태엽 카드로 행동력 보충, 다음 턴 행동력(예비 동력). 네페르: 야호다 카드로 행동력이 늘 때마다 체력이 가장 높은 적에게 균열 1.
- 일루가: 파티 전원 보호막(각자 방어력의 계수만큼), 되비춤, 보호막 기반 피해. 턴 종료 시 남은 본인 보호막의 36%(30% × 플린스 1.2)가 다음 턴 공격력에 더해진다. 플린스: 공격받은 전투원의 보호막이 0이 되면 공격자에게 방어력 기반 40%.
- 키니치: 필살기 버튼 = 모드 전환(게이지 0, 턴당 1회, 붕괴 중 불가, 전환할 때 아쥬의 참견 생성, 전투 첫 전환에만 컷인). 추적 모드: 연타 카드 타수 +1(턴당 2회, 말라니). 분쇄 모드: 대상 방어력 -30%, 장막 피해 2배(카치나). 연타 1타마다 추적흔 1(최대 10). 파트너 지원도 모드에 따라 말라니/카치나.
- 리니: 드로우와 버리기. 리넷: 생성 카드 30% 추가 생성, 리니 카드로 버리면 턴당 1회 전체 20%. 「카드 마술 C」는 뽑을 카드 더미에서 고르는 창이 뜬다.
- 사이노: 사이노 카드를 쓴 뒤 손에 편린만 2장 이상이면 칠흑의 심판으로 결합(X코스트, 종극). 사용 후 편린은 무덤으로, 명계의 깃털 생성. 타이나리: 첫 공격 카드 대상에 조준점(치명 +30%), 결합 시 조준점이 있으면 편린 +1.
- 신규 3인의 지원·필살기: 기획 표 그대로(리니 전체 200% + 3드로우, 사이노 단일 350% + 편린 3장 생성).

## 기획에 없어 정한 것 (바꾸려면 알려 주세요)
1. 키니치의 「추적」/「분쇄」 표시가 붙은 카드는 **어느 모드에서나 쓸 수 있다.** 모드는 파트너 보너스만 정한다.
2. 카드 문구의 `[추적]`은 `「추적」`으로 적었다(대괄호 꼬리표를 없애 달라는 이전 요청).
3. 레벨: 공격·보호막 +10%/레벨. 장비: 공격 +2 → +10%, +4 → +20%, 첫 공격 +5 → +25%.
4. 바르카·플린스의 "+30% / +20%"는 곱연산으로 읽었다(추가공격 30% → 39%, 전환 30% → 36%).
5. 두린 협공은 두린 자신의 카드에는 발동하지 않는다.
6. 쓰지 않은 칠흑의 심판은 턴이 끝나도 손에 남는다.
7. 리넷 지원의 리니 보호막은 150%, 길잡이 불빛의 정신부담 경감은 10으로 두었다.
8. 사이노 필살기의 편린 3장은 찌르기·발톱·응시 한 장씩.
9. '유일'은 보상에서 두 장째가 나오지 않게만 막는다(복제 보상은 아직 없음).
10. 키니치·리니·사이노의 합류·정신 안정 대사는 **임시 대사**다(story-scripts.js). 원문을 받으면 교체한다.
11. 적 체력 배율을 10 → 9로 낮췄다. 새 카드 수치로 자동 원정이 이전보다 어려워져서 맞춘 값이다.

## 이전 세이브
없어진 카드(바늘 궤적, 서약의 경계 등)는 덱·각성·잔불 각성에서 빠진다. 야호다 기본 덱이 바뀌었다(방어 태세 → 태엽 감기·은닉 보급품). 팔 결손의 드로우 -1은 5단계(부상 재설계)에서 다시 다룬다.
