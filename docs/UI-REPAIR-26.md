# v0.26 — 플레이 피드백 반영: 긴장감, 덱빌딩, 지도, 사건, UI 다듬기

v0.25를 직접 끝까지 플레이한 피드백(카오스 제로 나이트메어 비교)을 반영했다. 사용자가 고른 범위는 난이도·정신력 조정, 화면 겹침 수정, 전투 후 카드 보상, 분기형 지도, 사건 확충, 카제나식 날카로운 다크 UI다. 도입 장면, 캐릭터별 고정 트라우마, 보스 크기 키우기는 이번 범위가 아니다.

## 규칙 변경 (dist/engine.js, dist/map.js)
- **피격 → 정신 부담**: 공용 보호막을 뚫고 들어온 피해의 75%(`STRESS_PER_DAMAGE`)가 공격받은 전투원의 정신 부담으로 쌓인다. 완전히 막으면 0. 예고된 정신 피해는 기존 규칙(막으면 무효)을 유지한다.
- **야영은 한 가지만**: 휴식(체력 +25, 전원 정신 -8), 한 명과 밤새 이야기(그 동료 정신 -30), 준비(지원 +2, 모라 +10, 전원 정신 -4) 중 하나. 붕괴 극복은 여전히 거점 정신 안정에서만 가능하다.
- **깊이에 따른 적 강화** (`depthScale`): 9번째 지점(노드 8)부터 체력 ×1.08→×1.43, 피해 ×1.08→×1.33. 최종 전선 보스는 체력 ×1.30~1.46, 피해 ×1.30. 재탐사는 ×1.1.
- **정예 신체 위험**: 정예전에서 피해 10 이상의 예고는 신체 위험을 동반한다.
- 되돌리기 횟수는 바꾸지 않았다.

### 수치 확인
엔진만으로 도는 자동 플레이(공격 우선, 예고 피해가 크면 방어, 지원·필살기 사용)로 45판을 시뮬레이션했다.

| 항목 | v0.25 (직접 플레이 1판) | v0.26 (자동 45판) |
| --- | --- | --- |
| 정신 부담 최고치 중앙값 | 22 | 91 |
| 한 판 평균 붕괴 | 0 | 1.04 |
| 한 판 평균 전멸 | 0 | 0.69 |
| 최종 클리어 | 1/1 | 42/45 |

사람이 플레이하면 자동 조작보다 전멸이 적을 것으로 본다. 실제 사람 플레이 검증은 남아 있다.

## 전투 후 카드 보상
- 튜토리얼을 제외한 모든 전투 승리(일반·정예·보스)에서 편성 동료의 카드 3장을 제시한다. 한 장을 고르면 그 동료의 덱에 들어가고, 넘길 수도 있다. 같은 카드는 덱에 최대 2장까지만 제시된다.
- 보상 순서: 전리품 수령 → 카드 선택(`cardReward` 단계) → 전술 각성(있으면) → 경로 선택. 전리품을 넘기면 카드 보상도 없다.
- 새 카드 16장(전투원당 4장, `REWARD_CARDS`). 정신 부담 완화(calm)가 붙은 방어 카드를 각 전투원에 넣어 정신력 관리 수단을 늘렸다. 그림은 기존 skill-1~7을 재사용하고, 전술 각성 네 방향은 원본 카드 규칙에서 자동 생성된다.
- 덱에 같은 카드가 두 장 이상 있으면 uid에 `-2`, `-3`을 붙여 제거·실명 연결이 꼬이지 않게 했다. 첫 장의 uid는 기존 저장과 같다.

## 분기형 지도
- 첫 거점(노드 7) 이후 16칸을 열마다 2~3개 지점으로 만든다. 가운데 줄은 기존 ROUTE 지점(`route-N-a`), 위·아래 줄은 시드로 생성한 전투·정예·사건·야영(`route-N-b`, `route-N-c`). 거점 열은 한 칸.
- 지점끼리의 연결은 같은 줄과 옆 줄이며, 일부 대각선을 지운다. 모든 지점은 들어오고 나가는 길이 하나 이상 있다.
- 지도는 `s.map`, 현재 줄은 `s.lane`에 저장한다. 노드 번호의 의미(거점, 체크포인트, 재탐사 귀환)는 그대로라 기존 저장을 불러오면 시드로 지도를 다시 만든다.
- 거점의 "다음 스테이지"는 바로 다음 칸으로 들어가지 않고 경로 선택 화면을 연다.
- 경로 화면 왼쪽 아래 미니맵은 앞쪽 다섯 열을 보여 주고, 누르면 전체 지도(전설·보스 표시)가 열린다. 전체 지도에서 빛나는 지점을 눌러 바로 이동할 수 있다. 경로 선택지에는 지점 설명을 함께 보여 준다.

## 사건 확충
- 4종 → 12종. 새 사건 8종: 가라앉은 종루, 동료의 얼굴을 한 그림자, 버려진 야전 병동, 심연의 도박꾼, 서풍 매의 깃털, 균열 속 서고, 잔불의 사당, 말 없는 행렬.
- **주사위 선택지**(4개): d20 목표치와 성공 보상·실패 대가를 미리 보여 주고, 기존 3D 주사위 연출로 결과를 보여 준다. 야호다가 있으면 +2, 특정 동료에게 유리한 판정은 +2 더.
- **알 수 없는 선택지**(2개): 결과와 대가를 숨기고, 고른 뒤에 드러난다.
- 새 보상: 체력 회복, 전원 정신 부담 완화, 지원 게이지, 카드 3장 중 1장. 새 대가: 모라, 무작위 동료 부상.
- 한 판에서 같은 사건은 12종을 다 볼 때까지 반복되지 않는다.
- 설계된 대가가 있는 선택지에는 더 이상 무작위 대가를 덮어쓰지 않는다. 무작위 대가는 원래 대가가 없는 일반 선택지에만 붙는다. (v0.25의 "깊숙한 장비함"이 무료가 되던 문제)

## 화면 겹침·오류 수정
- 튜토리얼 안내 상자: 강조 대상뿐 아니라 적 정보·턴 종료·손패·HUD도 피해서 배치한다. 건너뛰기는 상자 안으로 넣고 "튜토리얼 건너뛰기"로 표기했다.
- 대화 건너뛰기 표기를 "대화 건너뛰기"로 통일.
- 보상 알림 토스트: 버튼처럼 보이던 하단 상자를 화면 맨 위의 얇은 알림으로 바꾸고, 카드 보상·각성 화면으로 넘어갈 때는 띄우지 않는다.
- 전술 각성·카드 보상 화면: 파티 HUD를 숨겨 제목과 겹치지 않게 했다. 카드 보상은 각성 화면처럼 실제 화면 픽셀 배치를 쓴다.
- 이야기 장면에서 스탠딩 그림 위에 있는 공용 체력 숫자에 어두운 그림자와 배경을 넣었다.
- 버릴 카드 선택창: 카드 아래 중복 효과문 제거, 긴 각성 효과는 글자를 조금 줄였다.
- 적 발밑 진영 표기를 선택 원 아래로 내렸고, 피해 숫자를 더 진하게 했다.
- 거점 "다음 스테이지" 줄바꿈 방지.
- 메인 로비: 16:9 캔버스는 유지하고(v0.18 결정), 좌우 빈 띠에 로비 그림을 흐리게 채웠다. 진행 정보 패널과 메뉴 아이콘 뒤에 어두운 바탕을 깔아 대비를 확보했다.
- 바르카 지원 문구: "적이 하나뿐이면 피해 24"로 수정.
- 키라라 대사: 해요체로 통일하고 맞춤법 수정(키라라예요).
- VFX 팩의 음수 반지름 오류: 공급 원본은 해시가 고정돼 있어 수정하지 않고, `supplied-vfx.js`에서 canvas `arc` 반지름을 0 이상으로 고정했다.
- 빈 favicon을 넣어 매 접속 404를 없앴다.
- 튜토리얼과 도움말에 "막지 못한 피해가 정신 부담으로 쌓인다"는 안내를 추가했다.

## UI 디자인 (dist/feedback-v26.css)
카제나식 날카로운 다크 방향. 배치와 크기는 기존 시트를 따르고 시각 속성만 덮는다.
- 버튼: 모서리 컷(clip-path) + 컷 모서리에도 이어지는 얇은 금속 선. 기본 버튼은 반투명 검정, 주요 버튼은 옅은 금빛. 탭은 상자 없이 금색 밑줄.
- 창·대화창·안내 상자·전리품·상인 대사: 같은 컷 모서리와 금속 선, 반투명 검정 바탕. 창 제목 아래 짧은 금색 선.
- 선택 타일(경로, 사건, 서풍 매 응답): 왼쪽 강조선, 오른쪽 아래 컷.
- 지도 기호 색: 전투 회색, 정예 붉은 분홍, 사건 보라, 야영 주황, 거점 금색, 보스 붉은색. 현재 위치는 금색, 갈 수 있는 지점은 청록으로 깜빡인다(OS 동작 줄이기 시 정지).
