# 티바트 방어전 · 잔불 0.8 구현 결정

## 부상

| 부위 | 중상(2) 이상 | 결손(3) 추가 |
|---|---|---|
| 눈 | 2단계에서 자기 전용 카드 전체 블러 | 실명 / ?? / ? 카드. 남은 물리 덱에 존재하는 고유 카드 효과 중 무작위 선택. 실제 효과·강화·비용 적용 |
| 팔 | 부위당 카드 수치 효과 -20%, 소수점 내림 | 드로우 효과 부위당 -1 |
| 다리 | 부위당 피격 시 부상 위험 +15%p, 새 부상은 눈/팔로 진행 | 해당 캐릭터를 겨냥한 적의 피해 예고 +25%/부위 |

- 기본 부상 기술 확률35%, 다리 중상 두 부위 포함 최대65%(코드 안전상한80%). 보호막으로 모두 막은 공격은 부상 없음. 일반 공격도 다리 중상 시 위험이 생긴다. 코로전 지속피해는 별도 유지.
- 실명 효과는 뽑을 때/눈 결손 발생 때 지정해 저장한다. 열람·재접속으로 재추첨하지 않는다. 비용 부족/유효하지 않은 행동은 RNG·행동력·카드를 변경하지 않는다. 효과를 모르는 상태에서 위쪽 드래그는 필요한 적/아군 대상을 자동 선택하고, 대상 클릭 시 호환하는 대상에 적용한다.
- 정신 붕괴와 실명이 겹치면 ‘모든 전용 카드는 붕괴 카드’ 규칙이 우선이다. 극복 후 눈 결손이 남아 있으면 실명으로 돌아간다. 중상 블러는 붕괴 카드에도 적용한다.
- 팔의 -20%는 공격·보호막·준비·엄호·행동력·드로우의 수치와 추가 카드 효과에 적용한다. 파트너 지원은 영향을 받지 않는다. 전투원 필살기는 별도 능력이며 팔 결손의 드로우 제한을 받는다. 고정 코스트는 감소하지 않는다.
- 결손2부위면 전투 이탈. 파트너는 계속 지원한다. 거점 도착 자동 회복 없음. 생명의 불꽃 회복 행동으로 HP/신체만 복원하고 정신 안정은 대화 행동이다.
- 제공된 눈/팔/다리 결손 컷인은 처음 3단계가 되는 전투 연출에서 사용한다. 반복해 동일 결손을 맞아도 컷인을 중복 재생하지 않는다.

## 진행과 상점

- 튜토리얼: 첫 슬라임40HP/공격3, 첫 손패 집중 관통2·방어 태세1. 순서별 엔진 검증으로 다른 행동 우회 방지. 자유 전투 뒤 직접 영입 대화로 이동한다.
- 둘째 전투: 슬라임2×22HP, 바르카 지원 카드 안내. 두 번째 동료 합류 뒤 node7 첫 거점. 두 구간 스킵은 각 영입 선택지로 바로 이동한다.
- 기존 저장은 튜토리얼 완료로 취급해 진행을 보존한다. 라이브와 거점 스냅샷 모두 스키마3, eyes0/removedCards[]/removalCount0 기본값 추가.
- 제거는 카드명 전체가 아닌 UID1장에 적용. 캐릭터에 귀속돼 편성 교체·저장·전멸 거점 복원에 유지. 비용은 캠페인 공용25+15×제거횟수, 캐릭터당3장 이하로 줄일 수 없다. 완전 새 원정은 제거 기록 초기화.
- 야영은 동일 거점 UI, 지난 스테이지 화살표 없음. 회복/준비 각1회 후에도 남아 있고 출발 화살표로 나간다. 야영의 조작이 진짜 거점 체크포인트를 덮지 않는다.

## 테스트 페이지

- qa.html + qa.js/qa-fixtures.js/qa-feedback.js, 본편 iframe `?qa=1`. 게임키 `teyvat-embers-qa-v1`, 설정키 `teyvat-embers-qa-settings`; 본편의 두 키와 독립.
- 제어 메시지는 QA 모드에서만 같은 origin·정확한 부모 window에서 받는다. 임의 코드 실행 없이 load/resume/명시적 preview 명령만 받는다. 게임/테스트 JSON 입력은 hydrate 검증을 거친다.
- 장면17종. 상태 조절·편성·화면 크기·능력/붕괴/부상 컷인/상태/정신 안정/상점 미리보기. 테스트 프리셋은 초반을 건너뛴 별도 상태이며 실제 정상 밸런스 평가와 구별한다.
- 피드백: 자동 저장/초안, 분류·우선순위·재현·기대, 현재 테스트 상태 첨부, 수정/확인 표시, JSON 내보내기/최신 수정본 병합, 상태 재현. 서버 수집이나 자동 발송 없음. 게임 세이브만 첨부하고 본편 키는 읽지 않는다.
- 68개 자동 검증에 더해 실제 UI 검증 기록은 QA.md에 남긴다. Android 실기기/사람의 플레이 평가는 별도 필요하다.
