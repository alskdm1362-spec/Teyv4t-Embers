# v0.28 — 큰 화면 비율 수정과 화면 톤 통일

기준: v0.27(main dabd7ef) 위, 브랜치 `claude/v0.28`.

## 원인
`.modal.modern-surface`는 화면 전체(100vw × 100dvh)를 차지하지만, 안쪽 내용은 대부분 px 단위로 1280×720 기준에 맞춰져 있었다.
2554×1270 같은 큰 화면에서는 창만 커지고 내용은 그대로라서, 메뉴는 위가 비고 도감 아군 그림은 바닥에 작게 깔렸다.
`cardReward` 장면도 비확대 단계로 분류돼 있어 같은 문제가 있었다.

## 수정
- `viewport-layout.js`에 `uiScale(w,h)=max(1, min(w/1280, h/720))`를 추가했다. `app.js`의 `scale()`이 이 값을 `--uk`로 넣는다.
- `feedback-v28.css`에서 px 기준 모달(전투원 상세·상태·대화 제외)에 `zoom:var(--uk)`을 건다. 창 크기와 안쪽의 dvh·vw 값은 `--vh`·`--vw`(= 1dvh/--uk)로 바꿔 두 번 확대되지 않게 했다.
- `cardReward`·`refine`·`eventRemove` 장면은 큰 화면에서 `uiScale` 배율로 확대한다. 1280×720 이하에서는 이전과 같다.
- 전투원 상세와 카드 열람은 화면이 16:9보다 넓으면 16:9 무대 안에 배치해 옆으로 늘어나지 않게 했다.

## 화면 정리(로비 톤)
- 메뉴: 로비 타일과 같은 컷 코너 버튼(마름모 아이콘), 사선 무대 위의 파티 스탠딩, 체력·모라·기록 칸.
- 도감·아군: 캐릭터별 색 사선 카드에 스탠딩을 세로로 꽉 채우고 이름·역할을 붙였다. 탭은 금색 활성 버튼.
- 도감 상세: 사선 배경 위 스탠딩, 컷 코너 정보 패널, 목록 버튼 너비 수정.
- 전투원 상세: 각진 패널, 캐릭터 색 사선, 금색 활성 탭, 표 형식 능력치, 각진 로스터.
- 카드 열람: 캐릭터 색 머리띠, 금색 닫기, 청록 전술 각성, 각진 화살표·키워드 패널.
- 덱에 카드 더하기: 전장 배경을 흐리고 어둡게 깔고, 카드 묶음은 반투명 유리 패널 위에 놓았다.
- 확인 창: 닫기 버튼이 첫 줄을 가리던 문제 수정.
