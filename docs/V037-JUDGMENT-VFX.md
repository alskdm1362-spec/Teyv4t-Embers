## 영상에서 잰 박자
영상 중간부터 배속이 켜져 있다. 같은 카드(불꽃 카드)의 연출 길이가 0~12초 구간은 약 1.7초, 16초 이후는 약 0.9초라서 **16초 이후는 약 2배속**으로 보고 1배속으로 환산했다.

**카드 한 장 (1배속, 6.7~8.7초)**
| 시간 | 화면 |
|---|---|
| 0.0 | 손패의 카드가 빛나며 들린다 |
| 0.3 | 캐릭터 일러스트가 왼쪽에서 크게 들어오고, 카드가 가운데에 확대된다. 전장이 어두워진다. 0.3초 정지 |
| 0.6 | 카드가 흰 빛의 판으로 바뀐다(0.15초) |
| 0.8 | 빛의 판이 원소색 **네모 조각**으로 부서져 흩어진다(0.3초) |
| 1.1 | 일러스트가 빠지고 어둠이 걷힌다 |
| 1.4 | 대상에게 원소 폭발, 피해 숫자가 크게 튀었다가 줄어든다. 새 카드가 생기면 손패 자리에 세로 빛기둥 |

**결합 (2배속 구간 23.9~24.9초)**: 손패 빛기둥 → 편린 두 장(금·청)이 가운데로 겹침 → 흰 섬광과 가시 모양 빛살 → 푸른 빛 돔 → 암전 후 필살기 컷신(약 7.6초: 불바다 → 불사조 날개 → 손 클로즈업 → 별빛 십자 플레어 → 태양 → 화이트아웃 → 불타는 전장으로 복귀).

**공통 문법**: 큰 순간 직전에는 어둡게, 타격은 짧은 정지, 흩어짐은 네모 조각, 마무리는 화이트아웃.

## 잔불 연출 박자 (1배속 1.65초 · 짧은 연출 약 0.9초)
| 시간 | 내용 | 기법(Small Magic) |
|---|---|---|
| 0.00–0.30 | 세상이 어두워지고 대상 둘레만 밝게 남는다. 대상 발밑에 **일곱 변의 심판 문양**이 테두리부터 써진다(밝은 점이 따라감) | 어둠으로 강조 · 「써지는」 마법진 |
| 0.30–0.62 | 빛 조각이 대상으로 빨려 들고, 문양 안에서 작은 번개가 튄다. 0.42초쯤 사이노가 뛰어든다 | 모으는 중의 연출 |
| 0.62 | **잉크 프레임** 두 박자(흑백 → 반전, 착탄점 방사 광선과 원) · 하늘에서 노이즈 경로 번개(갈래 둘) · 땅 충격파 · 네모 파편 · 화면 흔들림 2.2 · 피해 숫자 | 잉크 프레임 · 노이즈 번개 · 영상의 네모 조각 |
| 0.66–1.06 | 어둠이 걷힌다 | |
| 0.71–1.40 | 문양이 바깥 테두리 → 룬 → 일곱 변 → 안쪽 원 순으로 조각나 사라진다. 보라·금 네모 불씨가 피어오른다 | 순서가 있는 사라짐 |

- 빛나는 선은 모두 **어두운 그늘 → 넓은 후광 → 몸 → 흰 심지** 4겹이라 밝은 배경에서도 읽힌다.
- 짧은 연출: 1.8배 빠르고, 잉크 프레임은 한 박자만.
- 움직임 줄이기(`prefers-reduced-motion`): 잉크 프레임 대신 옅은 섬광(0.25초).
- 결합 순간: 편린이 합쳐지는 70% 지점에서 **네 갈래 별빛 + 고리**(`combineFlash`, 0.5초).

## 함께 고친 것 (기존 버그)
행동력을 전부 쓰는 카드는 같은 행동 안에서 턴이 끝난다. 이때 `presentationPlan`이 그 카드의 타격 이벤트를 모두 버려서, **칠흑의 심판은 지금까지 타격 연출 없이 적 턴으로 넘어갔다**. 카드 사용(`play`)이면 첫 적 행동 앞의 이벤트를 남기고, 적 턴보다 먼저 보여 주도록 고쳤다. 턴 종료(`endTurn`)는 그대로다.
