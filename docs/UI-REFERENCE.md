# 전투 화면 · 연출 0.2

직접 확인한 이전 ‘균열의 몽상’의 `battle-ui.css`, `game.js` 구조와 카오스 제로 나이트메어의 전투 화면 배치를 참고했다. 원작 UI 이미지나 영상 프레임을 앱 리소스로 배포하지 않는다.

- 좌상단 공용 체력, 3인 상태 스트립, 캐릭터별 정신 부담과 필살기.
- 중앙 전장: 아군 왼쪽 / 적 오른쪽, 각 적 위 체력과 행동 예고.
- 좌하단 지원 게이지와 전용 파트너 3칸, 양쪽 더미.
- 하단 중앙 부채꼴 손패와 행동력, 우하단 원형 턴 종료.
- 카드 유형별 문양, 소유자 색상과 초상, 상세는 누르기·아래 드래그 유지.
- 위 드래그 시 실제 카드 미리보기와 가이드 화살표, 유효 대상 발광.

## 동작 원칙

`engine.js`가 결과를 한 번 확정·저장하고 `motion-plan.js`와 `motion.js`가 이벤트를 시각화한다. 연출 중 중복 입력을 막으며 연출이 결과·대상·난수를 다시 계산하지 않는다. 새로고침으로 연출이 끝나도 저장된 결과를 이어간다.

카드 UID를 이벤트에 기록해서 같은 카드가 턴 종료 때 버려졌다가 재셔플로 즉시 재등장해도 각각 이동한다. 적의 공격 대상은 다음 턴 계획이 아닌 해당 공격 당시 이벤트를 사용한다. 피해·정신 효과가 없는 준비 동작은 아군 조준과 타격선을 표시하지 않는다.

전투원 이탈·붕괴와 파트너 지원은 별개다. 파트너 원화가 없는 3개 슬롯은 다른 전투원 얼굴 대신 지원 문양을 사용한다. 원래 도트 전투 및 상태창 스탠딩을 유지한다.

빠른 진행과 OS 동작 줄이기를 반영한다. 히트스톱은 사용하지 않는다.

## 0.3 적용 범위 갱신

전투 배치는 유지한다. 위의 PixelFX 사용 설명은 0.2 이력이다. 0.3부터 전투·회복 효과는 `vfx.js`에서 직접 그린 원본 궤적·보호판·균열·불꽃을 사용한다. 거점에는 자동 회복 대신 별도의 무료 회복 행동이 있다.
