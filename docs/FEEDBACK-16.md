# v0.16 피드백 반영 내역 (카제나 비교 개선판)

## 변경 파일
- `dist/engine.js`: 전술 되감기(`undo`), 실시간 효과 예측(`predictCardEffect`), 파트너 탐사 패시브(`PARTNER_PASSIVES`), 희귀 잔불 각성(`SPARK_EFFECTS`), 붕괴 극복 각성 보상(`awaken`), 원정 기록 저장·삭제·보스 도전(`saveRecord`/`deleteRecord`/`challengeRecord`) 추가.
- `dist/app.js`: 전투 중 되돌리기 버튼·`Z` 단축키, 실시간 피해·처치·잔향 노출·장막 파괴 예측 배지, 부상 수치 배지, 잔불 각성(✦) 문양, 카드 키워드 인라인 툴팁, 확장형 전투 로그 서랍, 적 위험 행동 경고 배지, 아군 스프라이트 직접 탭 상태창 열기, 미니맵 클릭 전체 경로 보기, 도감 `원정 기록` 탭 및 거점/엔딩 저장 버튼 연결.
- `dist/feedback-v16.css`, `dist/index.html`: v0.16 전용 스타일시트 추가 및 연결.
- `tests/feedback-v16.test.mjs`: v0.16 신규 기능 6개 테스트 스위트 추가.

## 기존 규칙 및 자산 보존
- `GEMINI.md`의 0.15 기준(기존 붕괴 스탠딩·HUD 초상·1/2단계 컷인 분리, 기존 대사·수치·회복 규칙, 기존 저장 스키마 호환성)을 그대로 유지했습니다.
