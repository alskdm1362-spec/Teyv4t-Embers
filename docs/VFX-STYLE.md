# 직접 작성한 VFX · 0.3

`dist/vfx.js`는 외부 아틀라스, 라이브러리, 네트워크 요청 없이 Canvas2D 경로로 직접 그린다. 화면 절반 해상도의 투명 캔버스를 확대해 도트 전투와 어울리는 단단한 경계를 만든다. 하나의 캔버스가 동시에 재생되는 효과를 합성하며, 효과는 타격 숫자 아래에 위치한다.

## 형태와 움직임

- 로엔: 가늘고 긴 창끝, 짧은 이중 잔상, 작은 얼음 파편. 필살기는 창 자취 뒤에 각진 얼음 조각이 솟는다.
- 미탸: 보랏빛 곡선 세 겹이 시간차로 벌어진다. 기본 창 타격과 다른 넓은 면을 사용한다.
- 일루가: 금색 다각형 판이 아래에서 닫혀 방어막을 만든다. 피격 때 전면 일부만 밝아지고 바깥으로 작은 판이 튄다.
- 야호다: 초록색 짧은 교차 잔상과 정비 신호. 커다란 폭발 대신 선의 방향을 바꾼다.
- 바르카: 두꺼운 바람 세 겹. 발레리: 보랏빛 베일과 지원 조각. 플린스: 어두운 창끝 안에 얇은 밝은 날. 네페르: 짧은 칼자국 뒤에 약화 문양.
- 심연: 어두운 면을 먼저 놓고 뒤틀린 세 갈래 균열이 따라간다. 천공: 긴 금빛 판결선과 마름모.
- 회복: 발치에서 서로 어긋난 다섯 불꽃이 올라오며 작고 따뜻한 불씨가 흩어진다. 원형 화염 아틀라스를 사용하지 않는다.

일반 타격은 약 360–470ms, 넓은 기술·보호막은 500–620ms, 회복은 1100ms다. 빠른 진행·OS 동작 줄이기에서는 130ms 이하의 간단한 표식으로 줄인다. 히트스톱이나 화면 흔들림은 없다.

## API

```js
import {BespokeVFX,effectSpec} from './vfx.js';
const vfx=new BespokeVFX({short:()=>prefs.fast||matchMedia('(prefers-reduced-motion: reduce)').matches});
await vfx.play('spear', enemySprite, {from:heroSprite});
await vfx.play('guard', allySprite);
await vfx.play('flame-heal', healingActor);
vfx.clear();
```

`play`의 anchor는 실제 스프라이트 요소를 권장한다. `from`은 방향만 정하며 전체 화면을 가로지르는 고정 레이저를 그리지 않는다. `scale` 기본값 1, `strength`는 큰 기술에 최대 1.3배 크기 보정. `clear()`는 모든 Promise도 정리한다. 비활성 탭으로 전환하면 정리되고, 창 크기가 달라지면 캔버스를 갱신한다.

캔버스의 `data-active`는 현재 효과 이름, `data-frame`은 그린 프레임 수다. 브라우저 검증을 위한 읽기 전용 DOM 표식이며 게임 상태나 난수에 접근하지 않는다. `effectSpec`은 종류, 지속 시간, 팔레트의 복사본만 반환한다.

앵커 요소가 움직이는 컷인에서도 매 프레임 위치를 따라간다. 컷인 위 효과는 같은 캔버스를 일시적으로 상위 레이어에 배치하고 종료 후 원래 레이어로 되돌린다. 창 크기 변경·동작 줄이기·빠른 진행과 효과 취소는 게임 상태에 영향을 주지 않는다. `data-phase`는 forming / impact / fading / idle을 표시한다.

모양 검토용 원본 HTML은 `tests/vfx-review.html`에 보존한다. 개발 서버에서 보려면 임시로 `dist/qa-vfx.html`로 복사한 뒤 사용하고, 배포 파일에서는 제거한다.
