# 티바트 방어전 · 잔불 — 사용자 추구 UI 스타일 가이드 (v0.19 기준)

앞으로의 모든 화면·모달·기능 추가 작업은 아래 디자인 원칙을 기본 기준으로 따릅니다.

1. **아웃라인(박스 테두리) 최소화**:
   - 메뉴창, 환경설정, 도감, 전투원·파트너 열람, 전투원 상태, 정신 안정, 상점, 편성의 버튼은 박스 아웃라인을 제거합니다.
   - 강조가 필요할 때는 박스 테두리 대신 **퍼스널 컬러 세로선** 또는 **하단 가로 직선(밑줄)**, 그리고 비선택 탭 **어둡게 처리(opacity 저하)**로 계층을 표현합니다.
2. **제목 영역 최소화**:
   - `메뉴`(`pause-menu`)와 `기록`(`route`) 창을 제외한 나머지 모달/열람 창의 상단 제목 영역(`.surface-header`)은 제거합니다. 닫기(`×`) 버튼만 우측 상단에 간결하게 유지합니다.
3. **80% 비율 투명 모달 + 어두운 백그라운드**:
   - 전투원 상태, 정신 안정, 상점, 편성 등은 전체화면이 아닌 **화면 80% 비율 창**으로 띄웁니다.
   - 백그라운드 딤(shade)을 어둡게 처리해 가시성을 높이고, 스탠딩/편성/정신 안정 영역의 불필요한 배경 박스는 투명화합니다.
4. **로비 1280×720 비율 고정 + 가독성 유지**:
   - 로비 화면은 창 크기가 변해도 1280×720 기준으로 캐릭터·대화창·버튼 배치 비율을 유지하되, 화면이 작아져도 텍스트가 선명히 읽히도록 충분한 글자 크기를 확보합니다.
5. **화면별 전용 구조**:
   - **전투원·파트너 열람**: 좁은 좌측 초상화 레일(일러스트만) + 중앙 전투원/파트너 밑줄 전환 + 우측 3탭.
   - **전투원 상태**: 스탠딩 일러스트 클릭 불가 + 투명 배경 + 2탭(`상태` / `보유 카드`).
   - **정신 안정**: 80% 투명 창 + 캐릭터 페이드인 연출.
   - **상점**: 80% 창 + `카드 제거` 탭 우측 끝 배치.
   - **편성**: 80% 투명 창 + 상단 편성 일러스트 전체 표시 + 하단 `초상화 → 이름 → 설명` 수직 카드형 버튼만 배치.

## 0.20 구현 정정

로비는 1280×720 캔버스 내부 좌표를 사용한다. 모달은 별도의 실제 viewport 좌표를 사용하고, 내부 스탠딩/본문에는 다시 dvh 높이를 주지 않는다. 기본 창은 80%이며, 550px 이하 가로 화면 및 세로 보조 레이아웃은 90~92%로 확장한다. 내부 콘텐츠만 스크롤한다. 우선 적용 파일은 dist/interface.css이며 과거 feedback-v18/v19 CSS는 references/layout-history에 보관한다.
