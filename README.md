최신 0.14: 기존 붕괴 그림을 새 PNG 8장으로 교체. 실패 0~3회 1단계 / 4회부터 2단계, 네 번째 실패에 새 컷인과 선명한 유리 연출. 초상·카드·상태·정신 안정·도감까지 단계 연동. [교체와 검증](docs/COLLAPSE-14.md), [테스트·피드백](docs/QA.md).

## 실행

dist를 정적 HTTP 서버로 제공한다. 빌드 의존성 없음. file:// 실행은 지원하지 않는다. npm test로 엔진 검증.

## 범위

## 대사·그래픽 제한

일본어판관계별대사를완전히검증하지못했으므로첫구간은상황서술을사용한다. 한국어존대관계로임의대체하지않았다. 필살기컷인은정상스탠딩기반프레임연출, 붕괴는별도신규자세/표정그림. 파트너전용신규초상은아직없으며지원이름·효과구현.

## 0.2 전투 화면 (이전 변경 기록)

균열의 몽상과 카제나 전투 배치를 참고한 공용 체력·3인 상태 HUD, 부채꼴 손패, 중앙 AP, 좌측 파트너 지원과 우측 원형 턴 종료. 카드 드로우/버림/소멸/변질 플립과 공격 당시 대상 조준·타격을 순서대로 재생한다. PixelFX 아틀라스를 사용하며 히트스톱은 없다. 빠른 진행/OS 동작 줄이기를 반영한다. Mable 계정·MCP는 연결되지 않았다.

회귀 검사 25개와 실제 브라우저 조작을 확인했다. 이번 변경의 모바일·붕괴·파트너·격파 검증은 docs/QA.md, 참고 및 범위는 docs/UI-REFERENCE.md에 기록한다.

## 0.3 현재 규칙과 효과

거점 도착·재탐사 귀환에는 회복이 없다. 「생명의 불꽃 · 회복」을 눌러야 체력·부위 손상·이탈을 무료로 복구한다. 정신 부담·붕괴는 이 행동으로 회복하지 않는다. 거점 저장과 재시작은 회복 선택 전후의 실제 상태를 보존한다.

현재 전투 및 회복 VFX는 `dist/vfx.js`의 직접 작성한 Canvas 경로를 사용한다. 기존 PixelFX 아틀라스를 런타임에서 재생하지 않는다. 카드·타격·지원·심연·천공·불꽃의 형태와 타이밍을 별도로 정했다. 구체적인 아트 방향은 docs/VFX-STYLE.md.

## 0.4 카드 선택과 피드백

버리기·카드 더미·연마는 전투와 같은 카드 얼굴을 사용한다. 연마는 현재/A/B 효과를 나란히 비교한다. 로엔·미탸의 6장 시작 구성은 각각 방어 1장, 일루가의 방어·반격 역할은 유지한다.

전투는 고정 헤더 공간 없이 화면 전체를 채운다. 직접 그린 효과 아래에 색 발광을 합성하고, 약한 카메라 충격은 전투 장면만 움직인다. HUD와 손패는 고정. 설정에서 발광·흔들림을 조절하고 전체·음악·효과음 음량을 별도로 지정한다.

27개 오리지널 WAV를 제작해 창/대검/마법/보호막/심연/천공/카드/UI에 연결했다. 재현 스크립트 scripts/build-sfx.py, 출처·제작 원칙 docs/SFX-DESIGN.md. 외부 녹음 샘플을 복제하지 않았다. 전체 회귀 검사 33개와 가로 모바일 브라우저 직접 조작을 확인했으며, 실기기 플레이 및 청취 평가는 남아 있다.

## 0.5 제공 일러스트와 두린

일러스트.zip의 28장을 역할별로 통합했다. 전투에는 전투 표기의 SD 이미지, 일반 초상/필살기/붕괴 초상/붕괴 컷인에는 각각 제공된 별도 그림을 사용한다. 파트너 4명의 초상과 지원 컷인도 연결했고, 도감과 상태창의 일러스트 감상에서 전체 원본 구도를 확인할 수 있다. 세부 매핑/출처/투명도·인코딩 기록은 docs/CAST-ASSETS.md.

현재 편성 후보는 로엔(고정)·두린·일루가·야호다. 미탸를 제외하고 두린을 광역 공격 슬롯에 추가했다. 두린의 파트너 알베도는 보호막13과 AP1을 지원한다. 로엔·두린은 시작 6장 중 방어 각1장을 유지한다. 일루가·플린스는 기존처럼 플레이 가능하다.

저장 스키마2는 스키마1을 읽을 때 기존 미탸/발레리 기록을 두린/알베도로 이관한다. 성장·강화·장비·붕괴·신체 손상·전투 카드·공격 대상·거점·컬렉션·RNG를 보존한다. 보스/지역 규칙과 수동 회복은 변경하지 않았다. 36개 검사와 실제 브라우저 신규 진행/구버전 저장 복원/붕괴 전환/가로 모바일 조작을 확인했다. Android 실기기 및 사용자의 플레이 평가는 남아 있다.

## 0.6 추가 일러스트·카드 양식·장면별 BGM

일러스트2.zip의 스탠딩5장을 기본 초상에 연결했다(로엔·두린·일루가·야호다·바르카). 기존 전투 SD와 필살기/붕괴 컷인은 유지한다. 기존16종 카드의 기본/강화 그림에 스킬카드28장을 배정하고, 붕괴4유형에 캐릭터별 붕괴카드2장씩을 연결했다. 카제나의 전면 그림·얇은 프레임·좌상단 코스트·작은 분류 태그를 참고해 손패/선택/강화 공용 카드 틀을 다시 구성했다. 강화 A/B는 효과를 보존하며 같은 강화 그림을 사용한다.

후반 연결 장막과 악몽영주 구간에는 배경 B, 영역수호자와 최종 파수꾼 구간에는 배경 A를 사용한다. 초반·야영·거점·재탐사에는 기존 배경을 유지한다. 몬스터14장은 dist 밖 references/monsters에 참고용으로만 보관했다.

제공 BGM5곡을 장면별로 선택하며, 같은 곡의 재생 위치 유지·짧은 전환 페이드·탭 숨김 정지·기존 음량 설정을 지원한다. 47개 검사와 데스크톱/844×390/640×360 실제 브라우저 카드 조작을 확인했다. Android 실기기, 사람의 플레이 평가, 스피커/헤드폰 청취 및 곡 끝 루프 연결 평가는 남아 있다. 세부 배정과 검증은 docs/ILLUSTRATIONS-2.md, docs/BGM-DESIGN.md, docs/QA.md.

## 0.7 손패·컷인·거점과 경로 선택

손패는 상단1/3만 노출하고, 포인터 롤오버/클릭/숫자키로 한 장만 펼친다. 펼친 카드의 효과는 중앙 정렬, 70% 어두운 표면과7px 배경 블러다. 폰트는 제공 배포의 Paperlogy400/500/700이며 OFL 전문을 동봉했다. 전투·거점 HUD는 어깨 크롭, 파트너 지원 버튼은 각 그림의 얼굴 위치를 기준으로 크롭한다.

필살기/파트너 지원은 테두리 박스 없는 화면 컷인으로 그림·스킬명·실제 효과를 표시한다. 정신 붕괴는 가로에서 인물 허리 위를 확대하고 유리 균열/파편과 현재 붕괴 설명을 보여준다. 세로에서는 전체 그림 contain과 하단 설명을 사용한다. OS 동작 줄이기를 반영한다.

거점은 상단 바 없이 체력/정신 HUD와 전투원·메뉴 아이콘만 유지하며, 중앙 야영 불꽃 주위에 편성/연마/상점/정신 안정/명시적 회복을 배치했다. 좌우 화살표는 재탐사와 다음 전선이다. 정신 안정은 전투원 선택→파트너와4줄 대화→마치기 후 해당 전투원만 정신 부담30 감소/붕괴 회복. 새 전용 그림은 아직 넣지 않았다.

승리 보급은 수령 버튼에서 지급하며 넘어가면 모라와 경험치를 받지 않는다. 이후 travel 화면의 좌측 아래 미니맵에서 연결된 다음 지점을 고른다. 튜토리얼 영입 지점은 필수이며, 일부 전투/야영/정예 구간에는 다른 적 구성의 선택 경로가 있다. 각 선택은 저장된다. 전체 대규모 절차생성 캠페인을 추가한 변경은 아니다. 구버전 보상은 이미 지급된 기록으로 취급해 중복 지급하지 않는다.

튜토리얼은 로엔·바르카의 새 팬게임용 한국어 대화 초안 후 테두리색만 구분한 초상 없는 영입 선택지를 표시한다. 로엔은 바르카에게 반말한다. 54개 회귀 검사 및 실제 데스크톱/가로 모바일/세로 컷인을 검증했다. Android 실기기와 사용자 플레이 평가는 남아 있다.

## 0.8 티바트 방어전 · 잔불

제공된 main/로고, 새 스탠딩·파트너 카드·전투 붕괴 SD·눈 결손 카드·결손 컷인 58개를 통합했다. 손패는 편성순/캐릭터색으로 묶어 약한 부채꼴로 표시하며 사용 가능 카드는 절반, 불가 카드는 1/3, 선택 카드는 전체가 보인다. 전투원 필살기와 파트너 지원은 같은 도크에서 카드로 펼친 뒤 대상 클릭/드래그로 사용한다.

새 원정은 슬라임 2회 조작 튜토리얼→서풍 매 영입2회→첫 거점. 첫 손패는 집중 관통(2)·방어 태세(1) 고정이다. 기존 v1/v2 진행은 재시작하지 않고 스키마3으로 이관한다. 야영은 거점과 같은 화면이나 과거 지역 화살표가 없고, 휴식은 직접 선택한다. 키라라 상점에서 장비/개별 카드 제거 가능(25모라부터 +15, 소유자당 최소3장). 정신 안정 대화에는 제공 파트너 스탠딩을 사용한다.

눈/팔/다리 손상 규칙과 부상 도식, 일본어 인물 관계를 기준으로 한 한국어 반말 대화 방향을 유지한다. 상세 규칙은 docs/DEFENSE-08.md, 검증은 docs/QA.md.

### 별도 테스트 · 피드백

`/qa.html`에서 장면17종, 전투원/편성/부상/붕괴/행동력/지원, 컷인·상태·대화·상점 미리보기, 1280×720/844×390/640×360/390×740 화면을 선택할 수 있다. 게임은 `?qa=1`의 전용 진행·설정 저장 키만 사용한다. 본편 저장을 읽거나 덮어쓰지 않는다.

피드백은 분류/중요도/현재모습·재현방법/원하는모습과 당시 테스트 저장을 함께 남기며 자동 저장, 수정, 확인 상태 변경, JSON 내보내기/병합 불러오기, 첨부 상태 재현을 지원한다. 외부 전송은 없으며 사용자가 JSON을 채팅에 첨부해 전달한다. 브라우저 저장이 지워지면 로컬 기록도 사라지므로 내보내기를 사용한다. 작성 중인 초안도 내보내기에 포함한다.

## 0.9 시선 유도와 메뉴 정리

타이틀 조작 글꼴을 LevelUp Regular/Bold로 교체하고 hover/focus에 굵기와 발광을 적용했다. 튜토리얼은 실제 조작 대상만 밝게 남기는 암막과 대상 옆 안내/스킵을 사용한다. 카드가 올라오는 동안 강조 영역도 따라간다. 둘째 튜토리얼은 바르카 선택부터 시작하며 영입 때 지원 응답을 확인한 뒤 진행한다. 튜토리얼 직후 거점의 반복 탐사 버튼은 표시하지 않는다.

메뉴를 계속하기/환경설정/도감/타이틀로 통합했다. 도감은 아군 가로 스탠딩 목록과 적 이미지 목록, 클릭한 대상의 상세 화면으로 나뉜다. 일러스트 미리보기는 접었다 펼칠 수 있고 크게보기 및 실제 연출이 있는 항목만 연출보기 버튼을 제공한다. 상태 창은 가운데 보유 카드, 오른쪽 인체 도식과 적용 부상 효과로 정리했다. 상점의 카드 제거는 캐릭터별 그룹이며 카드 더미의 카드 밖 중복 설명을 제거했다. 붕괴 카드에는 검은 아웃글로우를 적용한다.

불꽃은 부상을 치료하고 공용 체력20(최대체력까지), 출전원 정신 부담5씩 회복한다. 이 작은 정신 회복만으로 붕괴를 해제하지 않으며 선택한 한 명의 파트너 정신 안정 대화가 별도로 가능하다. 대상 없는 전체 정신 안정 행동은 거절한다. 회복 수치는 저장/체크포인트에 동일하게 반영한다.

검증77개 및 실제 데스크톱/844×390/640×360 조작 결과는 docs/QA.md. LevelUp 폰트의 원배포/라이선스와 로컬 파일 해시는 assets/fonts/levelup/source.json 및 동봉 OFL 문서에 기록했다.

## 0.10 시네마틱 타이틀

로고 중심의 타이틀, 차분한 아이보리·금빛 메뉴, 느린 배경 이동·안개·잔불, 장면이 유지되는 시작→메뉴 전환으로 재구성했다. 유효 저장은 이어하기를 우선 표시하고 파티/현재 위치를 안내한다. 타이틀은 실제 화면 크기로 배치해 모바일 버튼 글자를 축소하지 않으며 게임 시작 후 기존 전투 배율로 전환한다. 디자인 참고와 범위는 docs/TITLE-DESIGN.md, 실제 검증은 docs/QA.md.

## 0.15 붕괴 스탠딩 복원 (현재 범위)

0.14에서 붕괴 스탠딩까지 교체한 범위를 바로잡았다. 상태창·정신 안정 선택/대화·도감 스탠딩·HUD 초상·카드는 기존 제공 그림을 복원했다. 새 8장 PNG는 붕괴 컷인에만 사용한다. 컷인은 실패 0–3회 1단계, 4회부터 2단계이며 4회 도달 시 재생과 선명한 후면 유리 연출은 유지한다. 도감 스탠딩은 기본/붕괴 두 탭, 단계별 컷인은 별도 항목이다. 0.14 문서의 스탠딩까지 교체했다는 내용은 이 정정으로 대체한다.

## 0.21 — 전투 안내와 로비·정보 화면 (현재)

- 튜토리얼은 카드 코스트 → 공격/방어 소진 → 행동력·턴 종료 → 다음 턴 AP 3 → 지속 자유 전투 안내 순서입니다.
- AP는 전투 하단, 카드 용어는 펼쳐진 카드 위, 확장 전투 기록은 좌측 중앙에 배치합니다.
- 캐릭터를 위로 올리고 전투 효과를 35% 확대했습니다. 근거리 공격은 타격과 피해 숫자 종료 후 복귀합니다.
- 중앙 로엔 / 좌측 진도 / 우측 원정·레이드·전투원 및 파트너·도감 로비로 개편했습니다.
- 메뉴·상태·상점·적 정보의 배경은 70% 어둡게 하고 블러 처리합니다. 작은 가로 화면에서도 메뉴 스크롤 없이 모든 버튼을 확인할 수 있습니다.
- 적 정보와 도감은 실제 기술·특징을 공유하며, 장비 장착 화면은 현재 장비와 새 장비를 함께 보여줍니다.
- 사건은 전투 무대와 하단 선택지로 구성합니다. 일반 보상의 비용은 무료/체력/정신 부담 중 무작위이며 고급 보상에는 확실한 대가가 있습니다.
- QA에 획득 장비 장착 장면과 미리보기를 추가했습니다. 검수 세부 내용: docs/UI-REPAIR-21.md.

## 0.26 — 플레이 피드백 반영 (현재)

- 막지 못한 피해의 75%가 맞은 동료의 정신 부담으로 쌓인다. 야영은 휴식·한 명과 대화·준비 중 하나만 고른다. 첫 거점 이후 깊이에 따라 적이 강해진다. 자동 45판 기준 한 판 평균 붕괴 1.04회.
- 전투 승리 후 카드 3장 중 1장(또는 넘기기). 새 보상 카드 16장.
- 첫 거점 이후는 열마다 2~3갈래인 시드 기반 분기 지도. 경로 화면의 미니맵을 누르면 전체 지도가 열리고 바로 이동할 수 있다.

- 튜토리얼 상자·토스트·각성 제목·체력 숫자 등 화면 겹침 수정. 카제나식 날카로운 다크 버튼·창(feedback-v26.css).

## 0.27 — 세이브 데이터와 로비 분리

- 로비는 원정과 별개의 허브. 원정을 끝내면(클리어·전멸·귀환) 참여한 전투원마다 빌드를 세이브 데이터로 남긴다(전투원당 3칸).
- 보스 레이드 개방: 세이브 데이터 1~3개로 출격, 진행 중인 원정은 보존.
- 전투 중 번뜩임: 빛나는 카드는 비용 0, 사용하면 세 각성 방향을 미리 보고 고른다. 전술 각성도 같은 미리보기.
- 카제나풍 로비 타일, 전투원 발밑 정신 게이지, 세이브 데이터·레이드 화면, 전투원 상세 세이브 탭.

## 0.28 — 큰 화면 비율 수정과 화면 톤 통일

- 1280×720보다 큰 화면에서 메뉴·도감·환경설정·상점·레이드 등 창 안의 그림과 글자가 작아지고 위가 비던 문제 수정. 창 전체를 한 비율로 키운다(`--uk`).

- 덱에 카드 더하기 화면은 전장 배경을 흐리고 어둡게 깔아 반투명하게 보인다.

## 0.29 — 상점·레이드·세이브 데이터 화면과 버튼 정리
