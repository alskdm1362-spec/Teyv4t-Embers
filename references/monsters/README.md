# 몬스터 참고 이미지 — reference_only

**reference_only: true / runtime: false**

이 디렉터리의 14개 PNG는 사용자가 제공한 몬스터 디자인 참고자료다. 전투·도감·프리로드·런타임 갤러리에서 사용하지 않는다. `dist/` 바깥에 보관하며 빌드 산출물에 복사하지 않는다.

- 원본 PNG 바이트를 그대로 복사했다. 리사이즈·크롭·배경 제거·재인코딩을 하지 않았다.
- 안전한 ASCII 이름 `monster-01.png`부터 `monster-14.png`까지 부여했다.
- 원래 파일명과 SHA256, 크기는 이 디렉터리의 `manifest.json`에 기록한다.
- 일부 원본에 포함된 배경이나 불완전한 알파도 그대로 보존한다.

기존 적 리소스를 이 이미지들로 교체하지 않는다. 이 자료를 바탕으로 향후 별도 제작이 필요해질 때 사용자의 범위를 다시 확인한다.
